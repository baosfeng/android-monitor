行为记录 · Logo 方案 v2Six Minimal Marks · Round 2

本轮语义基准只有两条：自我监控（我被持续记录）与 去除干扰（广告与个性化被剔除）。上一轮的眼睛 / 时间切片 / 盾与流 / 双环账本被判「太复杂」，这一轮反过来压到极限。

主标识 ≤ 2 个图元 统一线宽 20 / 256 24px 仍可辨 纯黑白单色可用 只用 path / circle / rect / line

简洁度硬约束：① 256 viewBox 内最多 2 个图元（一个元素可含多段子路径）；② 不得出现同心环 + 内部刻度 + 外圈弧线的三层堆叠；③ 24 / 32 / 48 / 96px 逐级实拍验证；④ 不靠渐变、发光、阴影表达含义；⑤ 无 filter / mask / 位图 / SVG 文字转曲，全部可直转 Android Vector Drawable。下列 6 个 mark 共用同一视线框（256×256 方形、同留白）与同一线宽 20，可逐像素对比。

我之环

RING OF SELF 图元 2 · circle ×2（1 描边 + 1 填充） · 线宽 20 24px 辨识度 5/5

主标识 · 256×256 viewBox

含义 / 为什么简洁 / 牺牲
含义：外环是「我在记录」的边界，环内那颗实心点就是被记录的我——一笔成环，一点定我。
为什么简洁：全组最少的图元数（2），没有任何内构、刻度、第二层弧，缩到 24px 依然是「一个圈 + 一个点」。
牺牲：图形不直说「去除干扰」，要靠品牌语境补；「圆环 + 点」是常见结构，只能靠比例（环粗 20、点径 54、留白 49）拉开差别。

单字标 M

LETTER M 图元 1 · path ×1（一笔 5 顶点折线） · 线宽 20 24px 辨识度 5/5

主标识 · 256×256 viewBox

含义 / 为什么简洁 / 牺牲
含义：M = Monitor（行为记录/监控）的首字母，一条折线一笔写完，字母本身就是「记录」这件事的名字。
为什么简洁：1 个图元，5 个顶点，等宽 20 的折线，没有第二条笔画——比任何图形都更接近「一笔画完」。
牺牲：完全放弃图形隐喻，不说「去除干扰」；中文「记」的极简重构至少要 4 笔（会超过 2 图元），所以本轮没做。

一句话自检 · 缩到 24px 后我肉眼看到了什么

下面每个缩略图都是 1:1 的 24px 实拍（左深底、右浅底），描述只写「看到什么」，不做设计解释。

24px 深底

L1 我之环：一个清晰的圆圈，中间一颗圆点，圈线没有断裂，两点关系一眼可读——最小尺寸下仍像「靶心」。 24px 辨识度5/5。

24px 深底

L2 缺口即净化：一个圈，正上方缺了一段：缺口净空约 8.5px，24px 下仍一眼看出不闭合，但整体更像朝上的马蹄形，而不是「完整的圈加一个小豁口」。4/5。

24px 深底

L3 点与线：一条横线和悬在上方的一颗点，两者间距清晰，小尺寸下几乎无损——但整体重心偏下。 24px 辨识度5/5。

24px 深底

L4 半环自我：一个朝右开口的 C 形弧，中间一颗点；小尺寸下弧的开口仍在，但和 L1 需要并排比对才能立刻分开。 24px 辨识度4/5。

24px 深底

L5 单字标 M：一个 M，两条竖线加中间一个深 V；笔画粗、间距大，24px 下最锐利，是全组最不容易糊的。 24px 辨识度5/5。

24px 深底

L6 呼吸节律：一个圆角方块，中间一条起伏曲线；24px 下波峰波谷仍分得清（峰谷差约 5.6px），但这是全组最细的细节，最怕再缩小。3/5。

把每个缩略再用 5× 像素放大逐个核对后的结论：6 个在 24px 下都还认得出，没有一个真正糊掉，差别只在余量。
余量最大的是 L5 单字标 M（一条等宽折线、笔画净距最大，24px 下轮廓依旧锐利）与 L1 我之环（全组最少结构，24px 下仍是干净的「圈 + 点」）。
余量最小的是 L6 呼吸节律：波形峰谷差在 24px 下只剩约 5.6px、线宽 1.9px，是本组最细的细节，可辨但最怕再缩；L2 缺口即净化 的缺口净空约 8.5px，24px 下读起来更像「朝上的马蹄形」而不是「圈 + 小豁口」，这既是它的辨识优势，也是它偏离「环」这一原型的风险。
