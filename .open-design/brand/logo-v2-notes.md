# Logo v2 · 六概念对比与推荐（极简轮）

语义基准：自我监控（我被持续记录）+ 去除干扰（广告/个性化被剔除）。硬约束：256 viewBox ≤2 图元、统一线宽 20、24px 可辨、纯黑白单色可用、可直转 Vector Drawable。

| 概念 | 图元数 | 24px 辨识度 | 含义贴合度 | 与上一轮「眼睛」的延续性 | 结论 |
|---|---|---|---|---|---|
| L1 我之环（环 + 实心点） | 2 | 5/5 | 4/5（监控直给，去干扰靠语境） | 中：环可看作虹膜的抽象，中心点延续「注视」 | 保留，最省事、最稳 |
| L2 缺口即净化（286° 圆弧） | 1 | 4/5 | 5/5（缺口 = 被剔除的干扰，最贴题） | 低：没有瞳孔，失去「在看」的暗示 | 保留，语义最强 |
| L3 点与线（基线 + 悬点） | 2 | 5/5 | 4/5（强调「正在被记录」） | 低：横线结构偏图表，与眼睛无关 | 保留，最小尺寸最省心 |
| L4 半环自我（210° C 弧 + 点） | 2 | 4/5 | 3/5（收进视野，去干扰更弱） | 中：C 弧 + 点可读作半只眼 | 备选，与 L1 同家族、相似度最高 |
| L5 单字标 M（一笔折线） | 1 | 5/5 | 2/5（无隐喻，只有名字） | 无：完全离开眼睛体系 | 保留，做品牌资产最强 |
| L6 呼吸节律（圆角方 + 波） | 2 | 4/5 | 4/5（持续记录的节律） | 无 | 可用，但细节余量最小 |

> 24px 辨识度是 5× 像素放大逐个核对 1:1 实拍后给的，不是估算：L2 缺口净空约 8.5px、L6 波形峰谷差约 5.6px（线宽 1.9px），其余各标笔画净距都在 4px 以上；6 个在 24px 都仍可辨。

## 推荐排序

1. **L1 我之环** — 全组最少结构（一个圈 + 一个点），24px 与 96px 表现一致，转 Vector Drawable 只要 2 条指令；同时离上一轮的「眼睛」最近，品牌不断层。
2. **L5 单字标 M** — 24px 下最锐利、最不像任何别人的图标；缺点是不表达「去除干扰」，更适合当第二资产（字标 / 启动页）。
3. **L2 缺口即净化** — 语义最准且只用 1 个图元；代价是 24px 下更像马蹄形，会弱化「环」的原型感，须接受这一变形。
4. L4 半环自我 — 与 L1 同家族、含义更弱，只作为 L1 的横向变体备用。
5. L3 点与线 — 缩得很稳，但横长比例在方形容器（图标 / 头像）里配重吃力。
6. L6 呼吸节律 — 24px 仍可辨，但细节余量最小，若上主标须锁死最小尺寸 24px 并禁止加发光 / 阴影。

## 落地建议

先按 L1 出一版 Android Vector Drawable（2 条 path 指令以内），同时把 L5 作为字标资产保留；L2 作为「去除干扰」功能模块的专属标记（跳过开关、拦截统计角标），主标与功能标分工，不必二选一。
