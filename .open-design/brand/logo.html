SPEC

通用规范与 Android 落地

色彩系统（唯一颜色落点 :root）

深色底var(--bg) ＋玻璃层 var(--glass) / var(--glass-2)
唯一强调色var(--accent)，深调 var(--accent-deep) 仅用于图标底
正文对比度主文字 var(--fg) ≈ 17.8:1；次级 var(--fg-2) ≈ 9.8:1；三级 var(--fg-3) ≈ 5.4:1（均 ≥ 4.5:1）
图标底色var(--icon-bg) ＋ var(--icon-glow) 几何辉光（是形状不是模糊，可矢量化）
取值位置本页所有原始色值（hex / rgba）只写在 :root，其余位置一律 var(--…)，可整段抄进 ui/theme token
Token 映射全部写在 :root，其余一律 var(--…)，可 1:1 抄进 ui/theme token（对应 checkUiStyle 门禁）

自适应图标落地约束

前景层 foregroundmark 缩放进 66dp 可见圆，四周留到 72dp 安全区，不触碰 108dp 画布边缘（圆形/圆角/方形遮罩都不会切到）
背景层 background纯色 + 1–2 个几何形；允许 <gradient>（API 24+），不允许模糊/位图
单色层 monochrome只用 mark 的 currentColor 版本，系统按壁纸取色；不含渐变与多色（主题图标）
图元白名单path / circle / rect / line；无 filter、无 mask、无 clipPath、无 image、无文字转曲
小尺寸保底24px 必须读出主体轮廓；细节（扫描弧 / 流曲线节点 / 账页横线）允许在小尺寸版删除
开屏现无启动页：Android 12+ 用 SplashScreen API（windowSplashScreen* 主题），冷启动直接复用本页 66dp 遮罩版

怎么挑（一句话决策）

要「延续现有语义、最不出错」→ C1 注视之眼；要「和仪表盘首页同一套语言、最现代」→ C2 时间切片；要「一眼看懂双主业、最有安全感」→ C3 盾与流；要「品牌故事最强、最像 Apple」→ C4 双环账本。选定后：落选概念在本目录内直接删除，选中概念的开屏动效见 logo-motion.html。
