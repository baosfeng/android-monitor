# 轨迹底图（免费瓦片）

> 一句话：轨迹卡右上角「底图」开关，打开后叠一层免 key 的在线瓦片，关掉就是纯本地自绘。

## 为什么默认关

底图要联网，而请求本身会暴露「你在看哪片区域」——App 把轨迹所在区域的瓦片编号发给瓦片服务商。
默认关 = 轨迹完全本地，一个字节不出网；要真实街道就手动打开，一次点击，之后记住选择。

开关存在 `trip_map` 这组 SharedPreferences（键 `basemap_enabled`），与功能开关（`feature_flags`）分开：
它只改变「轨迹卡怎么画」，不是一段独立能力，所以不进 `Feature` 枚举。

## 用什么源（实测 2026-10，上海家宽）

| 源 | 结论 |
|---|---|
| `tile.openstreetmap.org` | 连接被重置，国内不可用 |
| `a.tile.openstreetmap.fr/osmfr` | 可用，1.6~4.2 s/块，偏慢 |
| `server.arcgisonline.com`（Esri 街道图） | 0.4 s/块，中文标注，**默认用它** |

默认源在 `TileSources.DEFAULT`（`ui/trip/TileSource.kt`）一处改，切换不需要动其它代码。
`TileSource.templates` 支持多个入口按顺序回退，OSM 那一项就挂了三处（官方 + 法国 + 德国镜像）。

## 图源使用条款的三条硬要求

1. 请求带可识别的 User-Agent：`TileFetcher.USER_AGENT`，别用默认的 Java/xxx；
2. 同一块只下一次网：内存 LRU 6 MB + 磁盘缓存 16 MB（`cacheDir/map-tiles`），按最后访问时间淘汰；
3. 图上必须署名：`TileSource.attribution`，轨迹卡图例右侧与导出图右下角都印，单行省略但不删。

并发上限 `TileFetcher.MAX_PARALLEL = 4`；入口连不上就熔断 5 分钟，期间不再白等它的连接超时。

## 轨迹怎么和瓦片对齐

关键在**只用一个投影**：开底图时轨迹点、停留点、瓦片全走 Web Mercator（`TileMath`），
关底图时才走原来的自适应等距圆柱（`TripTrace.project`）。两种画法的停留圆半径、标签避让逻辑共用一份。

- 选级：取能装下轨迹包围盒的最大整数级，整体居中，允许四周留白；
- 瓦片级别比视图级别高 1 级（`RETINA_BOOST`），每张按 128dp 画，2x/3x 屏不糊；
- 纬度按 ±85.05° 截断，极区不会算出 NaN 或负的瓦片下标；
- 可见瓦片超过 120 张直接放弃（参数算错时的保护）。

## 失败怎么表现

单个瓦片拉不到就跳过那一块：底图缺角，轨迹照常显示，不弹错误、不阻塞。
导出时取瓦片有 12 s 总预算，超时就按已取到的画；一块都没有则整张按无底图导出。
