# 事件类型定义

本文档定义所有可采集的事件类型及其数据结构。每条事件记录均采用统一 JSON 格式上报。

---

## 1. 统一事件基结构

```json
{
  "event_id": "xxxx-xxxx-xxxx-xxxx",
  "event_type": "app_foreground",
  "timestamp": 1718000000123,
  "device_id": "device_uuid",
  "extra": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_id` | string (UUID v4) | 全局唯一事件 ID |
| `event_type` | string | 事件类型枚举值 |
| `timestamp` | int64 | 事件发生的 Unix 毫秒时间戳 |
| `device_id` | string | 设备唯一标识 |
| `extra` | object | 事件特有字段 |

---

## 2. 事件类型完整清单（37 种）

### 核心监控（5 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `APP_FOREGROUND` | 前台 App 切换 | AccessibilityService |
| `ACTIVITY_CHANGE` | 同一 App 内界面切换 | AccessibilityService |
| `SCREEN_CONTENT_DETECTED` | 界面内容识别 | AccessibilityService |
| `SCREEN_ON` | 屏幕亮起 | BroadcastReceiver |
| `SCREEN_OFF` | 屏幕熄灭 | BroadcastReceiver |

**APP_FOREGROUND 字段：** `package_name`, `app_name`, `activity_name`, `activity_class`, `from_package`, `from_activity`, `foreground_duration_ms`

**ACTIVITY_CHANGE 字段：** `package_name`, `app_name`, `from_activity`, `to_activity`, `to_class`

**SCREEN_CONTENT_DETECTED 字段：** `package_name`, `app_name`, `screen_title`, `screen_type`, `activity_class`, `confidence`

---

### 锁屏与解锁（2 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `UNLOCK_SUCCESS` | 解锁成功 | BroadcastReceiver (ACTION_USER_PRESENT) |
| `UNLOCK_FAILED` | 解锁失败 | 暂未实现（Android 限制） |

---

### 充电与电池（3 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `CHARGING_STARTED` | 开始充电 | BroadcastReceiver |
| `CHARGING_STOPPED` | 停止充电 | BroadcastReceiver |
| `BATTERY_CHANGED` | 电量变化 | BroadcastReceiver (粘性广播) |

**CHARGING_STARTED 字段：** `battery_level`, `charge_type`

**BATTERY_CHANGED 字段：** `battery_level`, `is_charging`, `temperature_celsius`, `voltage_mv`, `health`

---

### 网络（5 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `WIFI_CONNECTED` | WiFi 连接 | BroadcastReceiver + WifiInfo |
| `WIFI_DISCONNECTED` | WiFi 断开 | BroadcastReceiver |
| `MOBILE_DATA_CHANGED` | 移动数据切换 | NetworkCallback |
| `VPN_CONNECTED` | VPN 连接 | NetworkCallback |
| `VPN_DISCONNECTED` | VPN 断开 | NetworkCallback |

**WIFI_CONNECTED 字段：** `ssid`, `bssid`, `signal_strength`

**WIFI_DISCONNECTED 字段：** `connected_duration_ms`

---

### 外设（4 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `HEADSET_PLUGGED` | 耳机插入 | BroadcastReceiver |
| `HEADSET_UNPLUGGED` | 耳机拔出 | BroadcastReceiver |
| `BLUETOOTH_CONNECTED` | 蓝牙设备连接 | BroadcastReceiver |
| `BLUETOOTH_DISCONNECTED` | 蓝牙设备断开 | BroadcastReceiver |

---

### 应用管理（2 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `APP_INSTALLED` | 应用安装 | BroadcastReceiver |
| `APP_UNINSTALLED` | 应用卸载 | BroadcastReceiver |

---

### 通知（2 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `NOTIFICATION_RECEIVED` | 通知到达 | AccessibilityService |
| `NOTIFICATION_REMOVED` | 通知移除 | 暂未实现（需监听系统通知移除事件） |

---

### 系统状态（10 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `RINGER_MODE_CHANGED` | 情景模式变化 | ContentObserver |
| `CONNECTED_TO_PC` | USB 连接电脑 | BroadcastReceiver |
| `DISCONNECTED_FROM_PC` | 断开电脑 | BroadcastReceiver |
| `AIRPLANE_MODE_CHANGED` | 飞行模式切换 | BroadcastReceiver |
| `POWER_SAVE_MODE_CHANGED` | 省电模式切换 | BroadcastReceiver |
| `STORAGE_LOW` | 存储不足 | BroadcastReceiver |
| `STORAGE_OK` | 存储恢复 | BroadcastReceiver |
| `VOLUME_CHANGED` | 音量变化 | ContentObserver |
| `TIMEZONE_CHANGED` | 时区变化 | BroadcastReceiver |
| `LOCALE_CHANGED` | 语言区域变化 | BroadcastReceiver |

---

### 通话（1 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `CALL_STATE_CHANGED` | 通话状态变化 | BroadcastReceiver (TelephonyManager) |

**字段：** `state` (idle / ringing / offhook)

---

### 其他（3 种）

| 事件 | 说明 | 数据源 |
|------|------|--------|
| `SCREENSHOT_TAKEN` | 截屏事件 | 暂未实现（ContentObserver 监控截图目录） |
| `APP_CRASHED` | App 崩溃 | 暂未实现（需监控崩溃日志） |
| `HOTSPOT_CHANGED` | 热点切换 | 通过 NetworkCallback 部分实现 |

---

## 3. 还能增加的事件（未来迭代）

| 潜在事件 | 难度 | 说明 |
|---------|------|------|
| NFC 标签检测 | 中 | 需注册 `ACTION_TAG_DISCOVERED` 广播 |
| 相机打开/关闭 | 中 | 需轮询 CameraManager，有一定电耗 |
| 传感器数据（步数） | 低 | 读取 `MotionSensor` 或 Google Fit API |
| 前台服务列表变化 | 高 | 需持续查询 `ActivityManager.getRunningServices()`，电耗高 |
| 键盘弹出/收起 | 中 | AccessibilityService 可检测输入法窗口变化 |
| 分屏/自由窗口模式 | 低 | 监听 `ACTION_CONFIGURATION_CHANGED` |
| 屏幕旋转 | 低 | 监听 `Configuration.orientation` 变化 |
| App 内部购买/广告 | 高 | 需解析 Activity 内容，准确率低 |
| 剪贴板变化 | 中 | Android 10+ 限制后台读取剪贴板 |
| 定位服务开关 | 低 | 监听 `MODE_CHANGED_ACTION` |
