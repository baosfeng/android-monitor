# 记录类型定义（RecordType）

> 代码：`domain/.../model/RecordType.kt`、`Record.kt`。一条记录 = `type + action + timestamp + duration? + label + detail`。

## 统一结构

```kotlin
data class Record(
    val id: String, val type: RecordType, val action: String, val timestamp: Long,
    val duration: Long? = null, val label: String,
    val detail: Map<String, String>? = null, val owner: String = ""
)
```

`detail` 存为 JSON；`label` 是给人看的摘要（「微信」「开始充电」），由对应 `RecordHandler.createLabel()` 生成。

## 11 种类型

| RecordType | action | label 示例 | detail 键 | 来源 |
|---|---|---|---|---|
| `SCREEN` | `ON` / `OFF` / `UNLOCKED` / `LOCKED` | 屏幕亮起 / 屏幕熄灭 | — | `RecordReceiver`（屏幕、解锁广播） |
| `CHARGING` | `STARTED` / `STOPPED` | 开始充电 / 停止充电 | `type`（USB / AC / WIRELESS） | 电源广播 |
| `APP_USAGE` | `OPENED` / `CLOSED` | 微信 / 抖音 | `duration_ms`（CLOSED 时） | `UsageTracker`（前台轮询） |
| `WIFI` | `CONNECTED` / `DISCONNECTED` | 连接 WiFi / 断开 WiFi | `ssid` | `NetworkCallback` |
| `AUDIO` | `PLUGGED` / `UNPLUGGED` / `BLUETOOTH_CONNECTED` / `BLUETOOTH_DISCONNECTED` | 插入耳机 / 蓝牙连接 | `device` | 耳机 / 蓝牙广播 |
| `BATTERY` | `CHANGED` / `LOW` / `OKAY` / `SAVE_MODE_ON` / `SAVE_MODE_OFF` | 电量 85% / 低电量警告 | `level`、`plugged` | 电量 / 省电广播 |
| `PACKAGE` | `ADDED` / `REMOVED` / `REPLACED` | 安装了抖音 | `app_name` | 包管理广播 |
| `POWER_SAVE` | `ON` / `OFF` | 开启省电模式 | — | 省电广播 |
| `AIRPLANE` | `ON` / `OFF` | 开启飞行模式 | — | 飞行模式广播 |
| `PHONE_STATE` | `RINGING` / `OFFHOOK` / `IDLE` | 来电 / 通话中 / 挂断 | `number`（脱敏） | `PHONE_STATE_CHANGED` |
| `LOCATION` | `COORDINATE` / `ENTER` / `EXIT` | 到达公司 / 离开家 | `lat`、`lng`、`address` | 类型已定义，采集二期实现 |

另有开屏跳过写 `AD_SKIPPED`（detail 含命中的 `selector`、`confirmed`），归入记录表由 `RecordCollector.onSkipAd()` 处理。

## 关系

- **App 使用时长**：`APP_USAGE` 成对出现（`OPENED` → 切换/息屏时 `CLOSED` + `duration_ms`），由 `record/UsageTracker` 维护状态机。
- **通话隐私**：`number` 需脱敏（仅后 4 位或忽略）；LOCATION 的地理编码在 HyperOS 上可能不可用，可只存经纬度。
- **查询口径**：`RecordStore.getDailySummary()` 统计各类计数与亮屏时长（无记录段按 5 分钟估计），`getAppUsageRank()` 取应用时长排行。
