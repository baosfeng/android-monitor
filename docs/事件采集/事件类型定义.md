# 事件类型定义

本文档定义当前所有可采集的事件类型及其数据结构。每条事件记录均采用统一 JSON 格式上报。

> ⚠️ 当前仅保留导航/会话追踪相关事件（共 5 种），其余全部删除。

---

## 1. 统一事件基结构

```json
{
  "event_id": "xxxx-xxxx-xxxx-xxxx",
  "event_type": "app_foreground",
  "timestamp": 1718000000123,
  "device_id": "device_uuid",
  "extra": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_id` | string (UUID v4) | 全局唯一事件 ID |
| `event_type` | string | 事件类型枚举值 |
| `timestamp` | int64 | 事件发生的 Unix 毫秒时间戳 |
| `device_id` | string | 设备唯一标识 |
| `extra` | object | 事件特有字段 |

---

## 2. 事件类型完整清单（5 种）

### 2.1 APP_FOREGROUND — App 切换

**说明：** 用户从桌面或另一 App 切换到某个 App 时触发。

**数据源：** `MonitorAccessibilityService.handleWindowChange()` → `NavigationTracker.onAppSwitch()`

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `app_name` | string | 应用中文名 |
| `package_name` | string | 应用包名 |
| `from_app_name` | string | 来自哪个应用 |
| `foreground_duration_ms` | string | 上一应用的驻留时长（毫秒） |
| `nav_path` | string | 导航面包屑路径 |
| `nav_depth` | string | 导航深度 |
| `nav_index` | string | 变更节点索引 |

---

### 2.2 NAVIGATION_CHANGE — 导航路径变更

**说明：** App 内导航栈发生变化时触发，包含完整的面包屑路径。统一呈现 App 切换和内部页面跳转。

**数据源：** `MonitorAccessibilityService.emitNavigationEvent()`

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `app_name` | string | 应用中文名 |
| `page_title` | string | 当前页面标题 |
| `nav_path` | string | 面包屑导航路径，如「微信 > 发现 > 朋友圈」 |
| `nav_depth` | string | 导航深度（从 1 开始） |
| `nav_index` | string | 发生变化的节点索引（-1 表示根变化） |
| `nav_level_1` ~ `nav_level_N` | string | 各层级节点名称 |
| `nav_level_1_type` ~ `nav_level_N_type` | string | 各层级节点类型（app/page/content/overlay） |
| `to_activity_name` | string | 目标页面中文描述 |
| `from_app_name` | string | （仅 App 切换时）来自哪个应用 |
| `foreground_duration_ms` | string | （仅 App 切换时）上一应用驻留时长 |
| `content_text_1` ~ `content_text_N` | string | 页面关键文本（最多 8 个） |

**节点类型：**

| 类型 | 说明 |
|------|------|
| `app` | App 根节点 / 主页 |
| `page` | 常规页面（搜索、设置等） |
| `content` | 内容页面（聊天、文章、视频等） |
| `overlay` | 浮层（对话框、弹窗等） |

---

### 2.3 VIEW_CLICKED — 点击交互

**说明：** 用户在 App 内点击可交互元素时触发。

**数据源：** `MonitorAccessibilityService.handleViewClick()` — 监听 `TYPE_VIEW_CLICKED`

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `app_name` | string | 应用中文名 |
| `package_name` | string | 应用包名 |
| `click_text` | string | 点击元素的文本内容 |
| `view_id` | string | 被点击 View 的资源 ID |
| `current_activity` | string | 当前 Activity 类名 |
| `current_page` | string | 当前页面标题 |
| `page_context_1` ~ `page_context_N` | string | 页面上下文文本（最多 5 个） |

**App 专用处理器：** WeChatClickHandler 可在微信聊天列表中，将默认提取的时间戳文本替换为群聊/联系人名称。

---

### 2.4 ACTIVITY_CHANGE — 页面跳转

**说明：** 同 App 内 Activity 切换时触发。

> ⚠️ 当前版本中，ACTIVITY_CHANGE 不单独发射事件，而是通过 NAVIGATION_CHANGE 统一体现。此类型保留枚举值供未来使用。

---

### 2.5 RETURN_TO_PAGE — 回到之前浏览的页面

**说明：** 用户从另一 App 回到之前访问过的 App 页面时触发（30 分钟内）。

**数据源：** `AppSessionManager.restoreSession()` + `MonitorAccessibilityService.handleReturnWithSession()`

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `app_name` | string | 应用中文名 |
| `page_title` | string | 当前页面标题 |
| `previous_page_title` | string | 之前浏览的页面标题 |
| `duration_away_ms` | string | 离开时长（毫秒） |
| `duration_away` | string | 离开时长（可读格式，如"5分钟"） |
| `nav_path` | string | 恢复后的导航路径 |

---

## 3. 事件关系图

```
离开 App ──────────────────────→ AppSessionManager.saveSession()
                                   │
回到同一 App（30分钟内）───────────→ AppSessionManager.restoreSession()
                                   │
                                   ▼
                              RETURN_TO_PAGE
                                   
App 切换 ──────────────────────→ NavigationTracker.onAppSwitch()
                                   │
                                   ▼
                              NAVIGATION_CHANGE (nav_index=0)

同 App 内页面跳转 ────────────→ NavigationTracker.onActivityChange()
                                   │
                                   ▼
                              NAVIGATION_CHANGE (nav_index≥1)

用户点击 ──────────────────────→ handleViewClick()
                                   │
                                   ▼
                              VIEW_CLICKED
```
