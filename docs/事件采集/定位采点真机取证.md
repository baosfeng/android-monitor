## 已修的独立缺陷

`lastSuccessAtMs` 曾是纯进程内状态，装包重启后归零 → 自检显示「还没有成功定位」，与「真的从没采到」不可区分（本次观测里 `procLastSuccessAgoSec` 一直是 -1 就是这个）。已加进程启动一次性回填（`LocationSuccessSeed` + `RecordStore.latestLocationTimestamp`，IO 线程、只跑一次、查不到保持 null）。另修 debug `bypass_throttle` 新建实例导致健康统计分叉（`LocationCollector.adoptSample` 回写）。
