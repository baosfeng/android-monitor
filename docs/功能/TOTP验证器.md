# TOTP 验证器

> 本机客户端：解码 otpauth:// 后在本地算码，不联网、不上传、不是服务端。

## 入口与开关

- 唯一入口是**概览页标题行右上角的盾形图标**（锚点 `s01-goto-totp`）；不开底部 Tab（7 个已满）。
- 默认开启（`Feature.TOTP` 不在 `DEFAULT_OFF`）。设置 → 功能开关 → 验证器 可关；关掉只是收起入口，账户与密钥都保留。
- 模块内六屏都是 push 屏：列表 / 添加 / 扫码 / 手动输入 / 账户详情 / 备份与导入。

## 安全设计（三项默认全开，可关）

| 开关 | 落点 | 真实行为 |
|---|---|---|
| 禁止截屏 | `TotpSecureScreen` → 窗口 `FLAG_SECURE` | 进模块加、离开清；截图 / 录屏 / 多任务缩略图都空白 |
| 复制即焚 | `TotpClipboard` | 复制后 30 秒清空；**只清自己写进去的那串**（用户改过就不动），读不到也不清 |
| 后台遮罩 | `TotpScreenHost` 生命周期 | `ON_STOP` 盖一层遮罩，`ON_START` 撤回 |

- 密钥用 Android Keystore **AES-256-GCM** 加密后存独立 prefs（alias `totp_secret_key`），独立库 `totp.db`，不混进 `monitor.db`。
- 解密失败**不清数据**：账户仍在列表，显示「密钥不可读」占位，由用户自行删除 —— 唯一一份 2FA 密钥删了不可恢复。

## 备份格式

导出是可存成文件的纯文本三行：

```
AMTOTP/1
pbkdf2-sha256:210000
base64(salt16 || iv12 || ciphertext)
```

- 口令经 PBKDF2-HMAC-SHA256 派生 256 位密钥，载荷 AES-256-GCM 加密；**与 Keystore 无关**，换机可恢复。
- 口令不写进文件；口令丢失 = 备份不可解，没有后门。
- 导入：本应用加密包按内容自动识别（`AMTOTP/1` 头 → 要密码）；Aegis / 2FAS 明文 JSON 直接解析。Aegis 加密导出用 scrypt 多槽位，标准库无实现，**明确报错不支持**而不是用错算法解出垃圾。

## 边界与不支持

- 参数只收 SHA1/SHA256/SHA512 × 6/8 位 × 30/60 秒；不认识的参数一律拒绝，不静默算成另一个码。
- 不支持 Steam Guard 等非标准变体、桌面小组件、通知栏常驻。
- 扫码页申请 CAMERA 权限仅用于手电筒与后续预览；**相册识别**走系统选择器，不申请存储权限。
- 单条导入失败只跳过并展示原因，不中断整批；超过 1,000 条走分批提示。

## 代码位置

`domain/…/totp`（纯算法与模型，零 Android 依赖）· `app/…/totp`（数据层与加密）· `app/…/totp/ui`（六屏 + `TotpViewModel` + `TotpScreenHost`）。
