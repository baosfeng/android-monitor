# UI 界面模块

## 职责

Compose (Material 3) 声明式 UI：展示监控数据、开屏跳过、记账、局域网互传的界面与交互。包 `com.bsfeng.monitor.ui`（记账子模块在 `finance/ui`），基元组件在 `ui/components/`，设计 token 与规范见[设计规范](../UI设计/设计规范.md)。

## 导航结构

`MainActivity` 用单一 `Scaffold` + `NavigationBar`，**没有 NavHost**；Tab 是 `feature/Feature.kt` 的 `AppTab` 枚举，7 个：`OVERVIEW(0) 概览 OverviewScreen`、`LIVE(1) 实时 MainScreen`、`AD(2) 广告 AdScreen`、`FINANCE(3) 记账`（`FinanceRoute` 子路由：Main / AddTransaction / EditTransaction / Stats / Budget / Import，用 `BackHandler` 处理返回）、`TRANSFER(4) 传送 transfer/ui/TransferScreen`、`SETTINGS(5) 设置 SettingsScreen`、`QUOTA(6) 额度 ui/quota/QuotaScreen`。

- **枚举顺序 ≠ 显示顺序**：枚举下标供 `EXTRA_START_TAB` 深链用（`MainActivity` 里的 `*_TAB` 常量与之一一对应），新 Tab 只能追加末尾；显示顺序由 `FeatureCatalog.DISPLAY_ORDER` 决定（额度排传送前），可见性由 `FeatureFlags` 决定（概览 / 广告 / 设置常驻，传送默认关闭）。
- 6 个可见 Tab 时单项约 65dp：label 用 `labelSmall` + `maxLines=1` + `softWrap=false`，图标 22dp 防挤压。

全屏覆盖层：`SkipRuleScreen`（规则管理）、`WhitelistScreen`（白名单）、`ComponentGalleryScreen`（组件画廊）、`AppearanceScreen`（主题），由 `MainActivity` 状态控制显隐。

## 状态管理（`MainViewModel`）

`MonitorState`：`isMonitoring`、`recentEvents`、`todayEventCount`、`accessibilityEnabled` 等。公开 `StateFlow`：`state`、`isPaused`、`debugEnabled`、`watchWindowMs`。

| 方法 | 作用 |
|---|---|
| `loadData()` / `loadDataInternal()` / `refreshData()` | 加载最近事件 + 今日计数 + 无障碍状态；内部协程每 `POLL_MS` 轮询一次 |
| `loadMore()` | 分页加载更多历史事件 |
| `togglePause()` | 暂停 / 恢复监控（恢复时刷新） |
| `setWatchWindowMs(ms)` | 设置开屏监控窗口（5/10/15 秒，同时是内置规则时间闸门） |
| `toggleDebug()` | 调试模式（持久化到 `DebugConfig`） |
| `clearToday()` | 清空今日记录 |
| `refreshAccessibilityStatus()` / `checkAccessibilityStatus()` | 无障碍启用状态的三重判定（设置项 / 服务列表 / 服务实例） |
| `retry()` / `getDeviceId()` | 失败重试 / 设备标识 |

`MainViewModel` 由 `viewModel()` 在 Activity 内创建，各页面共享同一实例；暂停状态仅存内存，重启恢复默认。

## 边界与注意

- 事件类型分布只在「最近 N 条」上计算，不是全量统计。
- 调试模式持久化键 `debug_enabled`；隐藏入口需先解锁（`DebugConfig.unlock()` / `DebugGate`）。
- 顶部导航栏统一 `IOSNavigationBar`，卡片 / 弹层 / 状态位用 `ui/components/` 基元；颜色、字号、间距一律走 token（`checkUiStyle` 构建期校验）。
- 各业务页细节见各自模块文档：[开屏跳过](../开屏跳过/设计.md)、[自动记账](../记账/自动记账.md)、[局域网互传](../网络通信/局域网互传-实现记录.md)。
