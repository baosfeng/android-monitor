# 桌面小组件 · 设计

> 6 个组件全做。技术栈 [Glance 1.2.0](调研.md)（2026-08 稳定版）。视觉 = **C 版「柔和品牌色」**（原型 `.open-design/widgets-r2/08-prototype.html`，2026-10-26 用户拍板）。

## 通用规格（C 版：每卡一个色相）

- **一张卡 = 一个色相**：记账蓝 / 额度紫 / 健康绿 / 广告橙 / 传送青 / 快捷记一笔实色主色 `#007AFF`。
- **卡面**：圆角 24dp、内边距 16dp（1×1 用 12dp）；卡底是**极浅 tint**（浅色 `#F4F8FF` 这类、深色 `#16223A` 这类），不是纯白/纯黑。
- **内嵌分区面**：同色系深一档 + 14dp 圆角，用于底栏两块（收入 / 预算剩余）与读数块。
- **图标块**：26dp 实色圆角块 + 一个**字符符号**（¥ / % / ♥ / » / ↕）。用字符不用矢量图标：Glance 的 `Image` + tint 在 launcher 上渲染不稳（见[踩坑](../踩坑/小组件Glance渲染踩坑.md)）。
- **字阶**（SansSerif，不用等宽）：主数值 Wide 40sp / Compact 26sp / Tiny 17sp 全部 Bold；读数 20–22sp Bold；分区数值 15sp Bold；标签 12sp Medium。**不用 Monospace**（字距大、显单薄）。
- **进度条**：`LinearProgressIndicator` + `height(6–8dp)`，颜色跟卡色相；端头圆角仅 API31+。
- **色值**：全部在 `ui/theme/WidgetPalette.kt`（构建期 `checkUiStyle` 只放行 theme 包），组件侧只做 day/night 绑定。
- **尺寸档**（按**宽度**判，纯函数 `WidgetLayoutPolicy`；高度 < 45dp 一律降 Tiny）：
  - `Tiny` < 140dp（1 格）：图标 + 一个数字/状态词
  - `Compact` 140–280dp（2 格）：一个数字 + 进度，或两/三列读数
  - `Wide` ≥ 280dp（4 格）：主数值 + 进度 + 底栏两块分区
- **尺寸来源**：`AppWidgetManager.getAppWidgetOptions()` 的 `MIN_WIDTH/HEIGHT`，不用 Glance 的 `LocalSize`（实测 4×2 返回 110×110）。
- **点击**：整块 `actionStartActivity`，带 `EXTRA_START_TAB` 直达对应 Tab；快捷记一笔直达「记一笔」。
- **1×1 金额**：主动丢小数（`tinyMoney`），整数千分位完整，不截断。

## 刷新触发

| 触发 | 覆盖组件 | 节流 |
|---|---|---|
| `AlarmReceiver` 60s 心跳 | 全部已添加的组件 | 30s 内重复调用直接跳过 |
| `FinanceMutationSignal`（记账写操作） | `finance` | 立即 |
| 额度刷新完成 | `quota` | 跟随 1/3/6 小时调度 |
| 服务状态变化（无障碍开/关） | `health` | 立即 |

## 隐私与默认值

- 设置页「桌面小组件」分组：**隐藏金额**开关（默认关，开启后金额显示为 `¥••••`）+ 6 个「添加到桌面」按钮（`requestPinAppWidget`；小米不弹确认框，按 `getAppWidgetIds` 校验结果）。
- 不做最近事件明细、不做通知正文、不在 widget 内发起网络请求。

## 实现约束

- targetSdk 37：widget 只传文字与小图标，**不传大图**（Android 17 的内存上限 `6 × 宽 × 高` 字节，超限直接抛异常）。
- 数据读取全部在 `Dispatchers.IO`；组件内不持有 Activity/ViewModel。
- 进程被回收后所有组件从 SQLite / SharedPreferences 重建，不依赖内存态（`transfer` 除外）。
- **卡壳只用单层 `Column(fillMaxSize)`**：外层 `Box(fillMaxSize + padding)` 再套内层 `fillMaxSize` 会被量成 0（见[踩坑](../踩坑/小组件Glance渲染踩坑.md)）。

## 实现落点

| 文件 | 职责 |
|---|---|
| `widget/WidgetDataProvider.kt` | 5 个组件的数据读取（IO + 逐项兜底；额度只读快照不联网） |
| `widget/WidgetFormat.kt` | 文案格式化：`money` / `tinyMoney` / `count` / `percent` / `ageText` |
| `widget/WidgetLayoutPolicy.kt` | 尺寸档纯函数 `tierOf` |
| `widget/WidgetStyle.kt` | 卡壳 `WidgetCard`、`IconBadge`、`Section`、`Stat`、`Bar`、`Pill`、字阶 |
| `ui/theme/WidgetPalette.kt` | 每卡 5 面色 token + 全局/语义色（浅深两档） |
| `widget/XxxWidget.kt` ×6 | Glance 组件 + receiver |
| `ui/SettingsWidgetSection.kt` | 设置页「桌面小组件」分组 |

## 已知限制

- `cornerRadius` 只在 API 31+ 生效：29/30 上卡片与图标块是直角（HyperOS 无影响）。
- 桌面占格因机型而异（4×2 可能变 5×3），布局按 dp 档位适配，不写死格数。
- 锁屏小组件未适配（Android 16 起 Pixel 支持，国内 ROM 不保证）。
