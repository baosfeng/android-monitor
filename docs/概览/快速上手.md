# 快速上手

## 环境要求

- **JDK:** 25（`export JAVA_HOME=/opt/homebrew/opt/openjdk@25`）
- **Gradle:** 9.8.2（用仓库自带 Wrapper，不要用本机 gradle）
- **Android SDK:** compileSdk / targetSdk 37，minSdk 29
- **Android Studio:** Ladybug 或更新版本

## 构建与安装

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@25

./gradlew build                       # 首次同步 + 编译
./gradlew test                        # 单元测试
./gradlew assembleDebug               # 产物 app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease             # 需签名配置，见发布指南

# 一行：测试 → 打包 → 覆盖安装
./gradlew test && ./gradlew assembleDebug \
  && ~/android-platform-tools/adb install -r app/build/outputs/apk/debug/app-debug.apk
```

> adb 一律用全路径 `~/android-platform-tools/adb`（见 [ADB 调试指南](../开发指南/ADB调试指南.md)）。

## 首次运行

1. 真机或模拟器（API 29+）安装 Debug APK。
2. 开启无障碍：设置 → 无障碍 → 已安装的应用 → 行为记录 → 开启；判定逻辑见 `util/AccessibilityStatus.kt`。
3. 按需授权：使用情况访问（应用使用统计）、通知访问（元信息）、定位（位置采集默认关闭）。

## 应用入口与 Tab

`app/src/main/java/com/bsfeng/monitor/MainActivity.kt`：单一 `Scaffold` + `NavigationBar`，Tab 由 `feature/Feature.kt` 的 `AppTab` 枚举状态驱动（**没有 NavHost**）。

| `AppTab` 下标 | 标题 | 页面 |
|---|---|---|
| 0 OVERVIEW | 概览 | `ui/OverviewScreen.kt` |
| 1 LIVE | 实时 | `ui/MainScreen.kt` |
| 2 AD | 广告 | `ui/AdScreen.kt` |
| 3 FINANCE | 记账 | `finance/ui/FinanceMainScreen.kt`（含统计 / 预算 / 导入子路由） |
| 4 TRANSFER | 传送 | `transfer/ui/TransferScreen.kt` |
| 5 SETTINGS | 设置 | `ui/SettingsScreen.kt` |
| 6 QUOTA | 额度 | `ui/quota/QuotaScreen.kt` |

- **枚举顺序 ≠ 显示顺序**：下标供通知深链 `EXTRA_START_TAB` 使用，顺序不可改，新 Tab 只能追加末尾；显示顺序由 `FeatureCatalog.DISPLAY_ORDER` 决定（额度排在传送前）。
- 概览 / 广告 / 设置是常驻 Tab；其余看 `FeatureFlags` 是否开启，关闭时入口隐藏。传送、位置采集默认关闭。

## 后端地址

仓库内只有占位地址。真实地址写进**不入库**的 `local.properties`：

```properties
serverBaseUrl=http://<your-server>:<port>
```

未配置时 `BuildConfig.SERVER_BASE_URL` = `https://your-server.example.com`（`app/build.gradle.kts`），此时不发任何数据。

| BuildConfig 字段 | 默认值 | 说明 |
|---|---|---|
| `SERVER_BASE_URL` | `https://your-server.example.com` | 后端地址，来自 `local.properties` 的 `serverBaseUrl` |
| `UPDATE_BASE_URL` | 空 | 私有更新源 |
| `UPLOAD_INTERVAL_MS` | `5000` | 预留参数，当前无上传调度消费 |
| `BATCH_MAX_SIZE` | `50` | 批次上限 |
| `CACHE_MAX_DAYS` | `3` | 本地缓存保留天数 |
| `RETRY_MAX_ATTEMPTS` | `5` | 失败重试上限 |
| `NOTIFICATION_CONTENT_ENABLED` | `true` | 是否采集通知内容 |

> 客户端当前一个请求都不发：`uploadBatch()` 是二期桩（恒返回 0），注册 / 心跳有封装但无调用方。
