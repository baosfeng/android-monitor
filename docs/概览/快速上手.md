# 快速上手

## 环境要求

- **JDK:** 25（`export JAVA_HOME=/opt/homebrew/opt/openjdk@25`），JDK 21 仍可回退
- **Gradle:** 9.8.2（使用项目自带的 Gradle Wrapper）
- **Android SDK:** API 37
- **Android Studio:** Ladybug 或更新版本

## 构建命令

```bash
# 克隆项目后首次同步
./gradlew build

# 编译 Debug APK
./gradlew assembleDebug

# 编译 Release APK（需配置签名）
./gradlew assembleRelease

# 运行测试
./gradlew test
```

## 在真机/模拟器运行

### 方法一：Android Studio（开发调试）

1. 打开项目 → 等待 Gradle 同步完成
2. 连接真机或启动模拟器（API 36）
3. 点击 Run 按钮
4. 首次安装后，在系统设置中开启无障碍服务：
   - 设置 → 无障碍 → 已安装的应用 → 行为记录 → 开启

### 方法二：命令行打包安装

```bash
# 构建 Debug APK
./gradlew assembleDebug

# 覆盖安装到已连接手机
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 一行完成：测试 → 编译 → 安装
./gradlew test && ./gradlew assembleDebug && adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 应用入口

**`app/src/main/java/com/bsfeng/monitor/MainActivity.kt`**

应用使用 Jetpack Compose 构建 UI，采用 Navigation Bar 的三标签页结构：

| 标签页 | 功能 | Compose 文件 |
|--------|------|-------------|
| 实时 | 显示当前监控状态和最近事件流 | `MainScreen.kt` |
| 统计 | 今日事件统计和类型分布 | `StatsScreen.kt` |
| 设置 | 无障碍服务配置、监控开关、电池优化 | `SettingsScreen.kt` |

## 最小工作示例

```kotlin
// 手动触发一个事件
EventCollector.emit(EventType.SCREEN_ON)

// 从数据库读取最近 20 条事件
val events = AppDatabase.getInstance(context)
    .eventDao()
    .getRecentEvents(20)

// 手动上传一批未上报事件
val reporter = EventReporter(context)
reporter.uploadBatch()
```

## 应用配置

配置项在 `app/build.gradle.kts` 的 `defaultConfig.buildConfigField` 中定义：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `SERVER_BASE_URL` | `https://your-server.com/api/v1` | 后端服务器地址 |
| `UPLOAD_INTERVAL_MS` | `5000` | 上传间隔（毫秒） |
| `BATCH_MAX_SIZE` | `50` | 每批最大事件数 |
| `CACHE_MAX_DAYS` | `3` | 本地缓存保留天数 |
| `RETRY_MAX_ATTEMPTS` | `5` | 失败最大重试次数 |
| `NOTIFICATION_CONTENT_ENABLED` | `true` | 是否启用通知内容采集 |
