# 项目简介

## 一句话

Android 端行为监控 App：无障碍 + 系统广播采集应用使用、屏幕、充电、网络等记录，落本地 SQLite；另有开屏跳过、记账、局域网互传、额度监控、TOTP 验证器等自带功能。

## 核心能力（都以本地数据为准）

| 能力 | 状态与要点 |
|---|---|
| 行为记录 | 11 种 `RecordType` 落 `records` 表；前台 App 每 1 秒轮询 + `WINDOW_STATE_CHANGED` 互补，使用时长由 `UsageTracker` 累加 |
| 开屏跳过 | 无障碍 + CSS 风格选择器规则引擎，内置规则 + 订阅更新；命中写 `AD_SKIPPED` 并弹 1200ms 弹幕 |
| 记账 / 自动记账 | 账目 / 账户 / 交易 / 预算 + 统计；识别微信 / 支付宝**单笔账单页**弹确认浮窗，确认后幂等落库 |
| 局域网互传 | UDP 组播发现、HTTP 流式传输、sha256 校验、PIN 配对、断点续传；默认关闭 |
| 额度监控 | 多 provider 余额 / 用量聚合 + 阈值预警，凭据走 Keystore |
| 桌面小组件 | 6 个 widget，随 60 秒保活心跳刷新（30 秒节流） |
| 上报后端 | **仅设备注册可用**；`EventReporter.uploadBatch()` 是二期桩（恒返回 0），事件不出本机 |

## 设计原则

| 原则 | 落地方式 |
|---|---|
| 静默无感 | 无启动动画、无默认常驻通知；只在无障碍停止 / 进程被冻结时推一次告警（30 分钟冷却） |
| 省电优先 | 不额外开轮询源：定位采样寄生在 1 分钟保活心跳里，桌面组件同一条心跳刷新 |
| 零第三方业务依赖 | 数据库 / 网络 / JSON 全用系统 API；唯一例外是 TOTP 二维码解码的 zxing core |
| 手动 DI | `ServiceContainer` + `by lazy`，不引 Hilt / Dagger |

## 技术栈

| 项 | 技术 |
|---|---|
| 语言 / 构建 | Kotlin 2.4、Gradle 9.8.2（Kotlin DSL）、JDK 25 |
| UI | Jetpack Compose Material 3（BOM 2026.09.00），`AppTab` 状态驱动 7 个 Tab |
| 本地存储 | SQLiteOpenHelper（`monitor.db` / `finance.db`），无 ORM |
| 网络 | HttpURLConnection + org.json，无 OkHttp / Retrofit |
| 后台调度 | AlarmManager 1 分钟心跳 + 三个 receiver 开机补排，无 WorkManager |
| 异步 | Coroutines + Flow |
| 平台版本 | `compileSdk` / `targetSdk` 37，`minSdk` 29（Android 10） |
| 包名 | `com.bsfeng.monitor` |

## 工程约束

- `domain/` 是纯 Kotlin/JVM 模块（零 `import android.*`），领域逻辑在这里才能在纯 JVM 单测里跑。
- 每次改动出 APK 才算交付：`./gradlew test && ./gradlew assembleDebug`。
- 隐私红线：真机截图、屏幕原文、真实账目与身份信息不入库，见 [SECURITY.md](../../SECURITY.md)。
