# 架构总览

> 真实形状是两跳直连：事件源 → `RecordCollector` → `RecordStore` → SQLite。没有事件总线、没有 Handler 扇出、没有上传管道。

## 整体链路

```
事件源                                  采集                      存储
service/MonitorAccessibilityService ┐
record/RecordReceiver（系统广播）   ├→ RecordCollector ──→ RecordStore ──→ monitor.db
service/LocationForegroundService   │   emit：暂停闸门 +        insert /
skip/SkipEventRecorder（跳过命中）  ┘   registry 校验 + label    insertOrMerge
                                          │
                                          └→ UsageTracker（APP_USAGE 时长状态机）
```

## 分层

| 层 | 位置 | 核心类 |
|---|---|---|
| 表现层 | `MainActivity.kt`、`MainTabContent.kt`、`ui/`、`finance/ui/`、`transfer/ui/` | 7 个 `AppTab` 与各自 Screen / ViewModel |
| 领域层 | `domain/`（纯 JVM，零 android import） | `model`、`repository` 接口、`quota`、`totp`、`transfer`、`trip` |
| 数据层 | `data/DatabaseHelper.kt`、`data/repository/`、`record/` | SQLite 建表迁移、记录读写 |
| 基础设施 | `service/`、`network/`、`core/di/`、`util/` | 无障碍、保活、HTTP、手动 DI |

依赖方向：表现层 → 领域层接口 ← 数据层实现，基础设施被三者依赖。细则见[分层架构设计](../开发指南/分层架构设计.md)。

## 数据流

```
ACCESSIBILITY / 系统广播 / 定位服务 / 跳过命中
 → RecordCollector.onXxx → emit（暂停闸门 + registry 校验 + label）
 ├→ UsageTracker（切换时写 APP_USAGE/CLOSED + duration，再写 OPENED）
 └→ RecordStore.insert / insertOrMerge → monitor.db 的 records 表

读侧：UI 一律走 RecordStore（queryByDate / getDailySummary / getAppUsageRank）
网络：只有 EventReporter.registerDevice() 可用；uploadBatch() 恒返回 success(0)（二期实现），
      AlarmReceiver 因此不调上传
```

- 新增采集入口 = 在 `RecordCollector` 加一个 `onXxx`，调用方在 `service/` 或 `record/RecordReceiver`；不要在事件源里直接写 SQL。
- 新增记录类型 = `domain/model/RecordType.kt` 加 `data object` + 一个 `RecordHandler` + 注册进 `RecordHandlerRegistry.createDefault()`，不改已有分支。

## 依赖注入

手动 DI，不引 Hilt/Dagger：`MonitorApp.onCreate()` 建 `core/di/ServiceContainer`，全部依赖 `by lazy`；使用方经 `MonitorApp.instance.container.xxx` 取（30 处）或构造器注入。新代码优先构造器注入。

## 技术栈

| 项 | 技术 |
|---|---|
| 语言 / 模块 | Kotlin 2.4；`app`（Android）+ `domain`（纯 Kotlin/JVM） |
| UI | Jetpack Compose (Material 3)，Compose BOM 2026.09.00；Tab 由 `AppTab` 枚举状态驱动（未用 NavHost） |
| 本地存储 | SQLiteOpenHelper（`monitor.db` + `finance.db`），零 ORM |
| 网络 | HttpURLConnection + org.json，零 OkHttp / Retrofit |
| 后台调度 | AlarmManager 1 分钟心跳 + 各 receiver 开机补排，零 WorkManager |
| 异步 | Kotlin Coroutines + Flow |
