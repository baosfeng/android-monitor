# 页面语法

> 何时读：新增一屏、改一屏布局、或觉得「这屏和别屏不像」时。25 屏共用下面五条，新屏默认照抄，不在屏内自建第二套。

## 一句话结论

页头两种、卡片三档、间距四档、字号五档、彩色三层；屏内样式只引用 token，不写死字号与圆角。

## 1 页头

| 类型 | 结构 | 现有屏 |
|---|---|---|
| Tab 页 | 副标题（日期 / 计数）+ 大标题 28 + 右侧 1–2 个 44dp 圆形动作 | s01 / s02 / s03 / s04 |
| Push 页 | 左返回 + 居中标题 17 + 右侧动作 | s07 / s16 / s18 / s19 / s22–s27 |

- 副标题默认在前、大标题在后；s04 记账页为省首屏高度把副标题放在标题后，属已知例外。
- 动作区默认最多 2 个；第 3 个入口下沉到内容区首块。

## 2 卡片

| 类 | 圆角 | 内边距 | 用途 |
|---|---|---|---|
| `.card` | `--radius-lg` 18 | `--space-4` 16 | 内容卡：图表、列表、表单分组 |
| `.kpi` | `--radius-md` 12 | `--space-3` 12 | 指标瓦片（2×2 宫格） |
| `.group` | `--radius-lg` 18 | 0 16 | 设置项分组 |

- 同屏默认最多两档；瓦片放卡外，卡内不再嵌瓦片。

## 3 间距

默认只取 `--space-1 / 2 / 3 / 4`（4 / 8 / 12 / 16）：

| 档 | 用在哪 |
|---|---|
| 4 | 同一行内：图标与文字、数字与单位 |
| 8 | 同一信息块内：标题与正文、两行辅助信息 |
| 12 | 卡内区块之间、chip 组与列表之间 |
| 16 | 卡片之间、页面左右边距（`.pad`） |

- 屏内 2px 默认只用于行内微间距；3 / 5 / 6px 归到 4 或 8。
- 大间距用 `--space-5..12`（20 / 24 / 32 / 48），不再新增长尾数值。

## 4 字号

| token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12 | 辅助说明、时间戳、图例 |
| `--text-sm` | 14 | 副文、控件标签 |
| `--text-base` | 17 | 正文、列表主标题 |
| `--text-lg` | 21 | 区块标题 |
| `--text-xl` | 28 | 页面标题、KPI 主数值 |

- 图表轴标签 11px 是唯一豁免（父元素带 `data-od-min-fs`）。
- 屏内写死字号是「这屏和别屏不像」的第一来源；默认用 `var(--text-*)`。

## 5 彩色

| 层 | 用在哪 | 取值 |
|---|---|---|
| 语义色 | 收支、预算、错误、提醒 | `--success / --warn / --danger` 与 `-text` 压暗档 |
| 数据色 | 图表、分类、热力 | `--chart-1..16` 与 `--chart-N-ink` |
| 身份色 | 应用图标、服务品牌 | `--app-<slug>`、行内 `--k` |

- 每屏首屏默认至少一处数据色面积（图表 / 进度组 / 热力），整屏纯灰是例外而非默认。
- 彩色文字默认用 `-ink` / `-text` 压暗档；原色用于填充、描边与图形。

## 6 改完自检

```bash
node scripts/assemble-prototype.mjs --check
node scripts/check-anchors.mjs
grep -nE 'font-size:[0-9]' .open-design/src/screens/<屏>.html   # 期望只剩图表轴 11px
```

字号或圆角改动会改变行盒与卡高，跑完再按[对齐台账](原型实现对齐台账.md)对一次锚点几何。
