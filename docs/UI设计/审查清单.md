# UI 代码审查清单

> 审查 UI 代码变更时逐条核对，任何一条不通过 → 打回修改。

## 颜色
- [ ] 没有 `Color(0xFF...)` 硬编码（`ui/theme/Color.kt` 除外）
- [ ] 前景色优先 `LocalDesignTokens.current`（`MaterialTheme.colorScheme` 是历史入口，同名值见 LEGACY-TOKEN-MAP）
- [ ] 事件类型色使用 `DesignTokens.eventColor`（chart1..6），不用已下线的 `RecordType.toEventColor()`
- [ ] 财务语义色用 `danger`（支出）/ `success`（收入）/ `accent`（预算进度）
- [ ] 首屏至少一处「数据色面积」（图表 / 进度组 / 热力）；整屏纯灰要能给理由
- [ ] 彩色文字用压暗档（`-ink` / `-text`），原色只用于填充、描边与图形
- [ ] 每类信息固定一个颜色，颜色换了含义就跟着换（口径见[页面语法](页面语法.md) §5），不用已下线的 `FinanceColors`

## 字号
- [ ] 没有 `fontSize = X.sp` 裸写（`copy(fontSize = 9.sp)` 特例除外）
- [ ] 全部使用 `MaterialTheme.typography.xxx`（headlineLarge ~ labelSmall）；字号族暂未按主题 token 化，见[对齐台账](原型实现对齐台账.md)

## 间距
- [ ] 没有裸写 `4.dp` / `8.dp` / `16.dp` 等标准值
- [ ] 全部使用 `LocalDesignTokens.current.space*`（`MonitorSpacing` 是历史别名，0 引用）
- [ ] 有特定布局意义的非常规尺寸（如 52dp 时间列宽）用注释说明用途
- [ ] 屏内间距只取 4 / 8 / 12 / 16；3 / 5 / 6px 孤值已归到 4 或 8（口径见[页面语法](页面语法.md) §3）

## 圆角
- [ ] 使用 `LocalDesignTokens.current.radiusSm/Md/Lg/Pill` 而非 `RoundedCornerShape(X.dp)`

## 组件
- [ ] 导航栏使用 `IOSNavigationBar`（而非手动拼 Row + Text）
- [ ] 分组列表使用 `InsetGroupedCard` / `InsetGroupedSection`
- [ ] 设置项使用 `SettingsRow`
- [ ] 列表行使用 `IOSRow`

## 触觉反馈
- [ ] 开关/按钮点击附带 `HapticFeedbackConstants.CONFIRM`
- [ ] Tab 切换附带 `HapticFeedbackConstants.KEYBOARD_TAP`
- [ ] 没有重复震动的场景

## 无障碍
- [ ] 新改的可交互元素四条红线齐全（可读名 / testTag / 48dp 触达 / 状态语义），口径见 [无障碍基线](无障碍基线.md)
- [ ] 纯装饰 Icon 写了 `clearAndSetSemantics {}` 或 `// decorative` 注释，而不是无标识的 `contentDescription = null`

## 自动化检查
- [ ] `./gradlew checkUiStyle` 通过
- [ ] `./gradlew checkA11y` 通过（ERROR 0 处；WARN 只报不阻断）
- [ ] `./gradlew test assembleDebug` 通过
