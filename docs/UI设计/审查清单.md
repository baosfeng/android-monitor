# UI 代码审查清单

> 审查 UI 代码变更时逐条核对，任何一条不通过 → 打回修改。

## 颜色
- [ ] 没有 `Color(0xFF...)` 硬编码（`ui/theme/Color.kt` 除外）
- [ ] 前景色全部通过 `MaterialTheme.colorScheme.xxx` 引用
- [ ] 事件类型色使用 `RecordType.toEventColor()`
- [ ] 财务颜色使用 `FinanceColors.expense` / `income` / `budget`

## 字号
- [ ] 没有 `fontSize = X.sp` 裸写（`copy(fontSize = 9.sp)` 特例除外）
- [ ] 全部使用 `MaterialTheme.typography.xxx`（headlineLarge ~ labelSmall）

## 间距
- [ ] 没有裸写 `4.dp` / `8.dp` / `16.dp` 等标准值
- [ ] 全部使用 `MonitorSpacing.xxx`（xxs ~ huge）
- [ ] 有特定布局意义的非常规尺寸（如 52dp 时间列宽）用注释说明用途

## 圆角
- [ ] 使用 `MonitorRadius.xxx` 而非 `RoundedCornerShape(X.dp)`

## 组件
- [ ] 导航栏使用 `IOSNavigationBar`（而非手动拼 Row + Text）
- [ ] 分组列表使用 `InsetGroupedCard` / `InsetGroupedSection`
- [ ] 设置项使用 `SettingsRow`
- [ ] 列表行使用 `IOSRow`

## 触觉反馈
- [ ] 开关/按钮点击附带 `HapticFeedbackConstants.CONFIRM`
- [ ] Tab 切换附带 `HapticFeedbackConstants.KEYBOARD_TAP`
- [ ] 没有重复震动的场景

## 自动化检查
- [ ] `./gradlew checkUiStyle` 通过
- [ ] `./gradlew test assembleDebug` 通过
