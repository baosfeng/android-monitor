# 能力矩阵（原型→实现）

> 原型 propose 前先对本表自检：打勾即可落地，缺项会撞门禁。入口见 [设计规范](设计规范.md) · [动效与触觉基建](动效与触觉基建.md) · [无障碍基线](无障碍基线.md)。

## 1 支持的 Compose 基元

- Card / Row：`AppCard` / `GlassCard` · `InsetGroupedCard` / `InsetGroupedSection` · `IOSRow` / `SettingsRow`
- 对话 / 抽屉：`AppDialog` / `ConfirmDialog` · `BottomSheet` · `AnimatedScreenOverlay`
- 状态 / 骨架：`StateContainer` / `EmptyState` / `ErrorState` / `EdgeState` · `StateSkeleton` / `SkeletonRow`
- 导航 / 容器：`IOSNavigationBar` · `Scaffold` · `LazyColumn` · `Chip` / `SegmentedControl` · `Badge` · `IOSDivider` · `ToastHost`
- 输入 / 表单：`TextField` / `OutlinedTextField` · `AppSwitch` / `Checkbox` / `Toggleable`
- 视觉基元：`Modifier.tokenShadow()`、`fgFade()/accentFade()`、`pressFeedback()`、`staggerEnterAt()`

## 2 DesignToken 子集

- 主题：8 套浅色（apple / glassmorphism / notion / stripe / claude / ibm / kami / bento），**无深色，禁止 dark 变体**。
- `LocalDesignTokens.current`：132 个语义 token（bg/surface/fg/…/chartSeq、dur*、tapMin、space1..12、radius*、elev*）。
- 兼容层 `IOSColors` / `FinanceColors` / `categoryPalette` 已弃用；新代码统一走 token。家族：`Spacing` / `Radius` / `IconSize` / `monitorTypography`（headlineLarge~labelSmall）。
- 动效 token：`durPress/durState/durOverlayIn/Out/durPage/durChart`、`easeStandard/Spring/Out/In`、`motionFast/Base`。
- 取值入口屏内用 `LocalDesignTokens.current`；checkUiStyle 构建期  对齐。

## 3 动效 / 触觉

- 档位：`FULL / NORMAL / REDUCED`（MotionTier），系统动画缩放 = 0 强制 REDUCED；自动降档只降不升。
- 转场唯一入口 `ui/foundation/Transitions.kt`（slide/sheet/dialog/expand + AnimatedScreenOverlay）；禁裸 `slideInHorizontally()` 等。
- 按压缩放 0.96 + `pressFeedback()`；组件内置，外层勿再叠缩放 / pointerInput。
- 触觉六档 `HapticTone`（LIGHT/MEDIUM/HEAVY/SUCCESS/WARNING/REJECT），view.performHaptic，三重闸门。
- 数字滚动 `AnimatedNumber / animatedCount`；列表入场 `staggerEnterAt(index)`；长列表新挂载传 -1。
- 约束：所有动画值进绘制期（gpuSlideX/Y），Path/Brush 进 drawWithCache。

## 4 平台 / 触达 / 无障碍

- minSdk 29 / target+compile 37；Edge-to-Edge 强制；无 FGS。
- 无障碍四红线：可读名 / testTag / ≥44dp / 状态语义；ERROR 0 无豁免；WARN 只报。
- 静态门禁 `scripts/check-a11y.sh`；运行时 `debug-cli.sh ui audit [tag]`。
- 平台约束：精确闹钟需权限；JobScheduler 超时 ANR；广播需 EXPORTED 标志。

## 5 图表能力与限制

- 零第三方默认；自绘 `Canvas + DrawScope`；库准入需覆盖率 / APK / 版本影响取证。
- 图表：`BarChart`/`GroupedBarChart`（柱/分组）· `LineChart` · `AreaChart` · `ScatterPlot` · `PieChart`/`RingChart`/`RingProgress` · `Sparkline` · `HeatBar`/`heatCell`。
- 三色彩角色互不混：`chartSeq` 序列色 · `chart1..16` 分类色 · `heatRamp` 强度阶 · danger/success 语义对。
- 限制：无缩放 / 平移 / 十字准线 / 大数据量实时渲染；库加入须门禁第流程。

## 6 网络 / 数据约束

- 零第三方网络：HttpURLConnection + org.json；超时 10s；Bearer token。
- 当前不发请求：`registerDevice()` 无调用方、`uploadBatch()` 二期桩恒成功。
- 调度：batchMaxSize 50 / retryMaxAttempts 5 / cacheMaxDays 3；setInexactRepeating。
- 本地数据不上传（`LOCAL_ONLY_DETAIL_KEYS` 含 address）；token Keystore AES-GCM 无刷新。
- 图像：`AppIcon` 仅 PackageManager 取；无异步图加载库。

## 7 data-od-id / testTag 锚点协议

- 原型元素加 `data-od-id`；全站页面级锚点登记入 `scripts/anchor-ledger.tsv`（613 个，制表符）。
- 代码落地 `Modifier.testTag("锚点")`，须与 ledger 逐字一致；组件级锚点登记 `docs/交互设计/s12a-组件级锚点登记.md`。
- 对账 `node scripts/check-anchors.mjs`；自增 / 清单外缺失 exit 1。
- 作废 / 未实现：`scripts/anchor-retired.tsv`（状态：作废 / 原型外壳 / 待实现 + 理由）；作废锚点一旦落地必须删行或脚本红。

## 8 设计 proposal checklist

- [ ] 文案放 `stringResource` 或 strings.xml，无硬编码
- [ ] 色 / 字 / 间距 / 圆角全部走 token，无字面量
- [ ] 可交互元素四条无障碍红线齐（含 testTag、≥44dp）
- [ ] 动效走 MotionTier / Transitions，不裸 API
- [ ] 图表色彩角色单一、分类色按 sort_order % 16
- [ ] Screen 有空/错/边缘/骨架五态与 CTA
- [ ] 锚点 data-od-id → ledger → testTag 三方一致
- [ ] 深色 / 未支持的交互图表特性不要 proposed
- [ ] 提交前 `check-docs` / `check-a11y` / `check-anchors` 通过
