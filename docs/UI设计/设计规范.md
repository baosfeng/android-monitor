# UI 设计规范

> 实现目录 `app/src/main/java/com/bsfeng/monitor/ui/theme/`。
> Token 入口（以原型为唯一权威）：原型生成 → `DesignTokenTable.kt` → `GeneratedTokens.kt`（`chartSeq`/`chart1..16`）→ `DesignTokenCatalog.kt`（派生分类色板/热力阶/事件色/半透明覆盖）。屏内优先 `LocalDesignTokens.current`；`IOSColors` / `MaterialTheme.colorScheme` 是历史入口，同名值登记在 `GeneratedTokens.kt` 的 LEGACY-TOKEN-MAP，新代码优先走 token。

## 1. 设计哲学

基础框架 Material 3，视觉倾向 iOS（圆角分组卡片、扁平导航、柔和色彩）；字体 SF 层级映射；图标 Material Icons Extended。四条原则：清晰、一致、高效、平台亲和。

### 2.2 Material 3 ColorScheme

浅色 `iOSLightColorScheme` / 深色 `iOSDarkColorScheme`（跟随系统）。常用映射：`primary #007AFF`（主按钮、Tab 选中）、`background #F2F2F7`、`surface #FFFFFF`（卡片/分组背景）、`surfaceVariant #E5E5EA`、`error #FF3B30`、`onSurfaceVariant #49454F`（辅助文字）。

## 3. 字体

`Type.kt` 的 `monitorTypography` 映射 iOS SF 层级；页面只引用 `MaterialTheme.typography.xxx`。字阶对齐原型 token：`--text-xs 12 / --text-sm 14 / --text-base 17 / --text-xl 28`（`.open-design/parts/00-tokens.css:100-107`）。

| Token | 字号/字重 | 用途 |
|---|---|---|
| `headlineLarge` | 34sp Bold | 大标题、记账金额 |
| `headlineMedium` | 28sp Bold | 页大标题（`.h1`） |
| `headlineSmall` | 21sp SemiBold | 区块标题（`.h2`） |
| `titleLarge` | 17sp SemiBold | 导航栏标题 |
| `titleMedium` | 17sp SemiBold | 卡片头、空态标题（`.h3`/`.st-title`） |
| `titleSmall` | 17sp Medium | 列表行主标题（`.row-title`） |
| `bodyLarge` | 17sp Normal | 正文（`.tl-title`） |
| `bodyMedium` | 16sp Normal | 按钮、输入框 |
| `bodySmall` | 14sp Normal | 辅助说明（`.meta`） |
| `labelMedium` | 14sp Medium | 列表副标题、分组标签 |
| `labelSmall` | 12sp Medium | 时间戳、极小说明 |

等宽数字族（`monitorMono*`，原型 `--font-mono` + `tabular-nums`）：`monitorMonoNumber` 28sp Bold（KPI 主数值）、`monitorMonoKpi` 21sp Bold（统计页瓦片）、`monitorMonoBadge` 11sp SemiBold（角标）、`monitorMonoMeta` 14sp Normal（时间列、图例）。控件文字用 `labelLarge`（M3 默认 14sp/500 = `--text-sm`）。

规则：字号从 typography 引用，不写字面量；唯一例外是 9sp 类型角标（已封装 `labelSmall.copy(fontSize = 9.sp)`）；标题 Bold、列表项标题 Medium、正文 Normal。

## 4. 间距 / 圆角 / 图标

间距（`Dimens.kt` 的 `MonitorSpacing`）：`xxs 2`、`xs 4`、`sm 8`、`md 12`、`lg 16`（内容内边距、行间距）、`xl 20`、`xxl 24`、`xxxl 32`、`huge 48` dp。推荐用 token，不写字面量；有布局语义的尺寸（52dp 时间列、40dp 图标、180dp 图表高）可留字面量并加注释。

圆角（`MonitorRadius`）：`xxs 2`、`xs 4`（类型标签）、`sm 8`（按钮）、`md 10`（卡片、InsetGroupedSection）、`lg 12`（弹窗）、`xl 16`（底部弹窗）、`circle 999`。

图标（`MonitorIconSize`）：`xs 12`（Tab 栏）、`sm 16`（内联）、`md 20`（默认/App 图标）、`lg 24`（操作）、`xl 32`。

## 5. 组件

`Components.kt` 的 iOS 风格组件：`InsetGroupedCard`（圆角分组卡片）、`InsetGroupedSection`（带 header/footer 的分组卡片）、`IOSRow`、`SettingsRow`、`IOSNavigationBar`、`CategoryDot`、`IOSDivider`（带缩进）。

导航栏统一 `IOSNavigationBar(title, onBack, actions)`，不手拼 `Row + Text`。

```kotlin
InsetGroupedCard { IOSRow("行1"); IOSDivider(); IOSRow("行2") }
InsetGroupedSection(header = "标题", footer = "说明") { SettingsRow(...) }
```

### 5.2 图标基元

- `CategoryIcon(name, color, size = 34.dp)`：分类色 12% 淡底 + `radiusMd` 方块；线描图标 24dp（24×24、`strokeWidth 1.7`、`fill=none`），描边 = 分类色混 22% 前景；选中态由外层格子补 2dp accent 描边。
- `CategoryIcons.keyOf/drawableOf`：分类名 → `res/drawable/ic_cat_<key>.xml`；145 个分类（26 一级 + 119 二级）各自独立 key 与 drawable，唯一性由 `CategoryIconUniquenessTest` 保证。
- `AppIcon(packageName, appName, size = 30.dp)`：优先 `PackageManager.getApplicationIcon`（Bitmap、`Crop`、`radiusSm`），取不到回落「品牌色底 + 应用首字」（对应原型 `var(--app, var(--fg-2))`）。
- `AppIconCache`：`LruCache` 96 项、取图边长 144px，取图在 `Dispatchers.IO`，`peek()` 供首帧同步命中。
- `AppBrandColors.colorOf(pkg)`：表内用品牌色，表外中性 `fg2`。

取图分流默认：行标题「应用名在前」用 `AppIcon`；系统事件（屏幕/Wi-Fi/充电）用 `TypeIconDot`；`AUDIO` 行用类型图标（`detail` 只有 `device`，无包名）。统一在 `ui/live/LiveCards.kt` 的 `LiveEventRow` 按记录类型 + `detail["package_name"]` 分流。

### 5.3 设置页两条固定口径

| 位置 | 默认口径 | 依据 |
|---|---|---|
| 「监控时长窗口」chip 组 | 5 / 10 / 15 **秒**（`SkipConfig.WINDOW_OPTIONS_MS`） | 该值同时是开屏跳过引擎的匹配窗口和内置规则 `matchTime` 闸门；放宽到 15/30/60 分钟会改变引擎行为 |
| 「使用时长统计」「事件上报」两行 | 用状态 `Badge` 角标 | 无开关消费点：`UsageTracker` 无条件轮询、`EventReporter.uploadBatch` 为二期桩，做成开关即假开关 |

## 6. 动效

**三档强度**（`ui/foundation/MotionTier.kt`，设置页「动效与触感」可切，默认 `FULL`）：

| 档 | 保留什么 | 什么时候用 |
|---|---|---|
| `FULL` | stagger 逐个入场 + spring 过冲 + 数字滚动 + 图表动画 + 转场 + 按压缩放 | 默认 |
| `NORMAL` | 转场 / 数字滚动 / 按压缩放；stagger 归零（同时入场），spring 改无过冲 | 卡顿自动降档、老机型手选 |
| `REDUCED` | 全部直接落终态 | 用户手选「精简」、系统动画缩放 = 0 |

系统「动画时长缩放 = 0」优先级最高，恒为 `REDUCED`，用户选择保留、系统恢复后自动还原。

**卡顿自动降档**：`ui/foundation/JankMonitor.kt` 在前台按 `Choreographer` 采样，120 帧窗口内超标帧（> 2× 刷新间隔）占比 > 15% 且 ≥ 2 帧，从 `FULL` 降到 `NORMAL` 一次并落盘，**只降不升**；设置页显示「已自动降档」并提供「恢复默认」。挂在 `MainActivity.onResume/onPause`。

弹性：按压/缩放取 `t.springOf(MotionToken.Press)`，过冲量由 `--ease-spring` 控制点推导、刚度由 `--dur-press` 推导，不手写 `spring(dampingRatio = 0.5f, stiffness = 200f)` 这类魔数。

转场：全项目唯一实现是 `ui/foundation/Transitions.kt`（`slideInFromRight` / `sheetEnterFromBottom` / `dialogEnter` / `expandEnter` + 各自退出，`AnimatedScreenOverlay` 为整屏覆盖层一步式载体）。时长取 `durOverlayIn/Out`、`durPage`，缓动取 `easeOut/easeIn`；**不要**在调用点写裸 `slideInHorizontally()`（门禁第 4 项会失败）。Tab 切换无动画。

数字变化用 `AnimatedNumber` / `animatedCount`（曲线 `--ease-out`、`durChart`）；列表入场用 `Modifier.staggerEnterAt(index)`，长列表滚动新挂载的项传 `-1` 不起动画。

开屏（`ui/components/BrandSplash.kt`）：单一时钟驱动，整条时间轴一个 `Animatable`，各元素按 `segment(ms, delay, dur, easing)` 取切片（对应原型 `animation-delay + timing-function + fill:both`）；缓动取 `easeStandard/easeOut/easeSpring/easeIn`，时长复用 `durOverlayIn` 等 token。默认时序（出处：原型 §8 开屏，CSS 1599-1631 / JS 6028-6037）：

| 起始 | 元素 | 动画 | 时长 | 缓动 | 关键帧 |
|---|---|---|---|---|---|
| 0 | 整层 `.splash` | od-fade | 220 | easeStandard | opacity 0→1 |
| 60 | mark 环 | od-draw | 720 | easeOut | 自 3 点顺时针 `drawArc` sweep 0→360 |
| 300 | 进度条 | od-splash-bar | 1100 | easeStandard | scaleX 0→1（origin left） |
| 420 | mark 珠 | od-pop | 420 | easeSpring | opacity/scale .94→1 |
| 520 / 620 | 字标 / 副标 | od-rise | 420 | easeOut | opacity、translateY 10px→0 |
| 1600 | `.is-done` 淡出 | — | 240 | easeIn | opacity→0 |
| 1900 | 整层 | 回调 `onFinished` | — | — | 移除开屏 |

品牌标配方：三根强度柱各 380ms、`cubic-bezier(.22,.85,.3,1)`、延迟 200/100/280、落位 660ms（在 mark 窗口内）。减弱动效：元素直接落终态 → 400ms 起收起 → 700ms 结束（读 `rememberMotionEnabled()`，即 `ANIMATOR_DURATION_SCALE`）。几何：mark 96×96；字标 `headlineMedium`；副标 `bodySmall` + `muted`；进度条 120×3、轨道 fg 10%、进度 fg2、`radiusPill`。取证：与原型逐帧及 `getComputedStyle` 对照，最大偏差 5.1e-5。

## 7. 图表

选型原则：零第三方业务依赖前提下，图形默认 Compose Canvas 自绘，动效优先 Compose BOM 内置；自绘难以覆盖时选成熟图表库。

- 自绘：`androidx.compose.foundation.Canvas` + `DrawScope`（`drawArc/drawPath/drawLine/drawRect`），同源实现 `finance/ui/FinanceStatsScreen.kt` 的 `DonutChart`，依赖代价 0。
- 动效：`animateIntAsState`/`animateFloatAsState`/`Animatable`（count-up）、`animate*AsState + spring()`（弹簧）、按索引加 delay（stagger）。
- 选库触发条件：交互式图表（缩放/平移/十字准线）、大数据量实时渲染、图表类型成片扩张。准入逐项取证：覆盖率清单、APK 体积差、对 Compose BOM/Material3/Kotlin 版本要求的影响、被抬升 UI 组件整体回归、结果记入 [编译配置](../开发指南/编译配置.md)。
- 三角色互不混用：序列色 `chartSeq`（= `--accent`，柱/线/面积/仪表，同图同色）、分类色板 `chart1..16`（跨主题固定，扇形分片/分类圆点/图例）、强度阶 `heatRamp`（`.h0..h5` 透明阶梯 8/20/36/54/72/90%）、语义对 `danger`/`success`（收支，优先于分类色）。
- 要点：柱状图单色（取色循环会成「彩虹柱」）；折线/圆环/仪表只描边不填充（`drawStyle = Stroke`，原型曾因 `fill` 覆盖把环图填成饼）；分类身份色跨主题不变；屏内只读 `LocalDesignTokens.current`（`t.chartSeq`/`t.categoryDot(i)`/`t.heatCell(i)`），checkUiStyle 构建期核对；分类色按 `sort_order % 16`。
- 分工（方案对比页已选定）：占比用 `PieChart`（实心扇形 `useCenter + Fill`、无中心文字、角度自 -90° 顺时针 `sweep = 360×value/total`、分片 2dp `PIE_SEAM` 描边、128dp、`durChart` 错峰扫出、图例「色点+名称+数值+百分比」）；趋势用 `BarChart(showValues = true)`（顶部留白 22dp，`rememberTextMeasurer` 一次测量避免掉帧）+ `AreaChart(markPeak = true)`（标注峰值）；预算利用率用 `RingProgress(fraction)`，环形容器 + 中心数值用 `RingChart`。同一图形只用一种色彩角色。

## 8. 触觉反馈

全项目唯一出口是 `ui/foundation/Haptics.kt` 的 `view.performHaptic(HapticTone.XXX)`，业务屏不自判版本与系统开关。六档：`LIGHT`（开关、Chip）/ `MEDIUM`（Tab、FAB）/ `HEAVY`（长按）/ `SUCCESS`（保存完成）/ `WARNING` / `REJECT`（校验失败）。

**三重闸门**：系统触觉总开关（`HAPTIC_FEEDBACK_ENABLED`）、`View.isHapticFeedbackEnabled`、应用内开关 —— 任一为关都不震。强度档（轻 / 标准 / 强，设置页可配）在发之前做一次档位换算。开关与按钮点击必带；列表项建议；转场/滚动不带；同一操作不重复震动。

```kotlin
val view = LocalView.current
view.performHaptic(HapticTone.LIGHT)   // 旧写法 performConfirmHaptic() 是 SUCCESS 的兼容 shim
```

## 9. 布局与编码约定

层级：`MonitorTheme`（ColorScheme + Typography + Shapes）→ `Scaffold`（导航栏 + 安全区）→ `NavigationBar` + 页面内容。

- 命名：Screen 层 `XxxScreen`，私有组件 `XxxItem` / `XxxRow`。
- 参数：Screen 首参为数据/回调，末参 `modifier: Modifier`。
- 主题引用：色 → `colorScheme`，字号 → `typography`，间距 → `MonitorSpacing`。
- ViewModel：Screen 入口用 `viewModel()` 默认参数，下层用参数传入。
- 适配：`fillMaxSize()/fillMaxWidth()` 自适应，避免固定宽高（特殊布局除外）；底部用 `WindowInsets.navigationBars + Spacer(96.dp)` 给 FAB 留位。

`ui/theme/` 结构：`Color.kt`、`Type.kt`、`Dimens.kt`、`Theme.kt`、`Components.kt`。改颜色/字号/间距先改 `ui/theme/` 定义，页面不直接定义常量。
