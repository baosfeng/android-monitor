# 原型 → 实现 对齐台账

> 何时读：新增或修改一屏之前；原型与实现「看起来不一样」需要定位原因时。

## 一句话结论

两端自由度不对称：原型能写任意 px，实现受 token 门禁；差额靠人工翻译，翻译损耗就是返工轮次。> 三条损耗表、孤儿值处置、复跑命令与两个取数文件的用途已拆到[取数口径](原型实现对齐台账-取数口径.md)，本文只留结论与基线。

主档（间距 / 圆角 / 颜色）与 token 逐值一致，只剩原型侧孤儿值（处置见下）；**唯一系统性偏差是字号**：原型 `--text-xs..4xl` 随 8 套主题变，实现 `monitorTypography` 只有一套，换主题只换色不换字。

## 一模一样：可测判据

**P0 = 0**（原型可见锚点在实现里全部存在）+ 几何每边 ≤3dp + 字号一致 + 文案去空白后双向包含。复跑命令、两个取数文件的用途、锚点落点规则见[取数口径](原型实现对齐台账-取数口径.md)。

## 三条硬口径

1. **「待实现」不是豁免**：`anchor-retired.tsv` 只豁免**作废**（元素已不存在）与**原型外壳**（自检装饰）。`待实现` 说明设计保留、产品没做，**P0=0 只能来自锚点真的存在**，这类屏单列为「欠账屏」，不并入已收口统计。
2. **原型自身缺陷不复刻**：`s19-alert-switch` 原型 `.switch{width:56}` 缺 `flex:0 0 auto`，被 `row-body` 挤成 32.5（比自身 24px 滑块还窄），实现按声明值画 52 轨道；`s19-alerts` 三行各带的 36dp 行图标是 `aria-hidden` 纯装饰，不搬（状态由开关与角标承担），故 h+43.5 登记白名单；`s10` 的 `.row-sub{nowrap}` 让文字 368 > 容器 327，把右侧按钮推出屏外。
3. **能修的不登记**：字号差是 P0 必改；几何差先按原型 CSS 盒模型算，算不出再登记。

## 需设计确认后才能动

- **s09 的 IA 差异不是欠账**：原型 s09 是 10 个分组卡平铺的长页，实现是「一级页六组入口 + 二级页」；s09-window / -a11y / -monitor / -battery 属原型「监控与采集」区块、在实现里对应二级页，一级页本就对应不到。已在白名单写明原因。
- **字号不随主题**：跟随会让 8 套主题行高与换行同时变，需一次 8 主题真机截图。
- **历史别名**：`MonitorSpacing`（19 处，全在 autobook）与 `MonitorRadius`（6 处）。

## 行盒：CJK 撑高与「固定盒 + unbounded」解法

原型高度来自 CSS `line-height`（body 1.47），Compose 单行 `Text` 取字体行盒（中文 1.47 倍，17sp → 25dp），比原型高 2–12dp；`lineHeight`/`LineHeightStyle.Trim`/`includeFontPadding=false` 都压不动。
解法：外层 `Box(Modifier.height(原型行盒))` + `Text(wrapContentHeight(Alignment.Top, unbounded = true))`——布局按原型取值、字形完整溢出；直接给 `Text` 设 `height` 会裁掉字形下半。已应用：`OverviewHead` 30、`FinanceScreenHead` 29.4、`CardHead` 22、`TransactionRow`/`TokenRow`/`ListRow` 21.25/18.2、`OverviewKpiCard` 30.8、`AppearanceScreen` 29.4、`AdScreenHead` 30。

## 已知残差与边界

**几何对照的价值（实例）**：s22 的 `EmptyState` 在「有账户」时也无条件渲染，列表底下一直压着 333.9dp 的空态；肉眼看不出来（被列表盖住），只有 `s22-list` 的 h 差 333.9 才暴露。**EmptyState 专项扫描已完成**：`grep -rn 'EmptyState(' app/src/main/java/` 共 20 处，逐点核验条件渲染，**只有 s22 那 1 处有问题（已修）**；另发现 `FinanceEmptyState` 是死代码（无调用点），余 18 处都挂在 `when(FiveState)` / `if(空条件)` 分支下。

中文 12px 字宽（Badge 91 vs 原型 96，-5px）；原型卡高含 1px 边框、Compose border 只绘制不占位，`AppCard` **不补**这一圈（补了会让 `S07DailyAvgParityTest` 的卡内容宽断言变红，见设计规范 §5）；字体 metric / 系统 inset / 动态字号差异不会因 token 化消失，目标是把偏差压进可测阈值，不是像素全等。
