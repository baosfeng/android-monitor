## 1. 结论速览

| # | 结论 | 对本项目的含义 |
|---|------|---------------|
| 1 | **小程序开屏广告可以被无障碍服务跳过**，无需 root | 可覆盖，见 §4 规则原文 |
| 2 | 可行是因为广告页**仍有可点击的无障碍节点**（`[text="跳过"]`），且宿主 Activity 固定在 `com.tencent.mm.plugin.appbrand.*` | 现有 `SelectorParser` + `activityIds` 前缀匹配已够用 |
| 3 | 小程序**激励视频**（必须看完才发奖励）无法用无障碍跳过 | 只有 LSPosed Hook 能改「看完」状态 |
| 4 | 微信**未成年模式**没有「关广告」这条开关 | 「没广告」是**副作用**，不是功能，见 §6 |
| 5 | 真实机制：广告位载体入口被默认关闭 + 禁止自动化决策商业营销 | 见 §5 法规、§6 拆解 |

## 2. 广告组件类型 × 无障碍可点性（决定能力边界）

| 组件 | 形态 | 无 root 能否跳过 |
|------|------|-----------------|
| **小程序开屏广告** | 启动覆盖层 | ✅ 可点（§4 规则） |
| **全屏弹窗广告** | 覆盖层 | ✅ 可点（需「关闭」节点） |
| 插屏 `InterstitialAd` | 全屏 | ⚠️ 视有无关闭节点而定 |
| `ad`（banner / video / grid 格子） | 页面内原生组件 | ❌ 无关闭控件 |
| 激励视频 `RewardedVideoAd` | 强制倒计时 | ❌ 需伪造「已看完」 |
| `ad-custom` 原生模板 | 自定义布局 | ❌ 结构逐站不同 |

> 分界线：**有没有「跳过/关闭」可点节点**。开屏和弹窗有，常驻广告和激励视频没有。

## 3. 五类技术路线（GitHub 取证）

| 路线 | 代表项目 | 前置条件 | 能跳什么 |
|------|---------|---------|---------|
| 无障碍自动点击 | GKD / 李跳跳类 | 无 | 开屏、弹窗 |
| 宿主 Hook | [WeKite](https://github.com/SymonChu/WeKite) | root + LSPosed/Zygisk | 小程序 6 项：开屏/视频/激励/启动页等 |
| 包反编译 | KillWxapkg 等 | 需重签 | 改广告调用逻辑 |
| WMPF 调试注入 | [WMPFDebugger](https://github.com/evi0s/WMPFDebugger) | 电脑端 | 调 JS、改广告 SDK |
| 桌面进程劫持 | [WeSkip](https://github.com/FiresJoeng/WeSkip) | Windows | 作者已标「不可用」 |

[wechat_skipAds](https://github.com/winde03/wechat_skipAds) 是**视频号短剧**推广（非小程序），仅适配微信 8.0.78，自述「推广完全不出现」未经真机验证。

> 结论：**无 root 的普通 App，唯一可行路线是第一类。** WeKite 能「跳过激励广告并立即发放奖励」，靠的是 Hook 篡改「已看完」状态，无障碍做不到。

## 4. 可直接复用的规则（GKD 订阅原文）

来源：[Lin-arm/GKD_subscription](https://github.com/Lin-arm/GKD_subscription) `dist/gkd.json5` v614，包名 `com.tencent.mm`。

**开屏广告**（`order:-10`，窗口 10s）：

```
activityIds: ['.plugin.appbrand.ui.AppBrandUI',
              '.plugin.appbrand.launching.AppBrandLaunchProxyUI',
              '.plugin.appbrand.ui.AppBrandPluginUI']
规则0  actionDelay:800
       先匹配 [text="广告" || text="廣告"]，再匹配 [text="跳过" || text="跳過"]
规则1  matchRoot:true  actionCd:500
       @TextView[text*="跳过"][text.length<10][height<150] <<(25-n) FrameLayout <(1,2) * < [id="android:id/content"]
```

**小程序内弹窗广告**：`activityIds:'.plugin.appbrand.ui.AppBrandUI'`，排除含「跳过」的页面，匹配「关闭图标 + 同页出现 `[text="广告"]`」的结构。

> 关键点：广告页 Activity 落在 `com.tencent.mm` 包里且带 `appbrand` 前缀，所以 `activityIds` **前缀匹配**即可精准圈定，不必为每个小程序单独写规则。

**为什么必须加 `actionDelay`**：GKD 给 `actionDelay:800` 不是随手写的——开屏广告节点先出现、内容后渲染，过早点击首次大概率无效，常需补第二次（规则 1 的 `actionCd:500` 就是补点）。本项目调规则时同理，别在 `WINDOW_CONTENT_CHANGED` 一到就立刻点。

**为什么小程序比 App 开屏难**：广告渲染在微信私有 WMPF 容器与原生组件层，节点树不暴露广告内部结构，只能靠「`[text="广告"]` + 相邻 ImageView」这类**启发式结构匹配**，所以规则里要靠 `excludeMatches` 大量兜防误触。

## 5. 法规依据（「未成年人不给推广告」的出处）

| 条款 | 原文要点 | 链接 |
|------|---------|------|
| 《未成年人网络保护条例》**第二十四条**第三款 | **「网络产品和服务提供者不得通过自动化决策方式向未成年人进行商业营销。」** | [司法部法规库](https://xzfg.moj.gov.cn/front/law/detail?LawID=1694) |
| 《互联网广告管理办法》**第十二条** | 针对未成年人的网站/网页/App/公众号等媒介，**不得发布**医疗、药品、保健食品、化妆品、酒类、美容广告，及不利于未成年人身心健康的网络游戏广告 | [中国政府网](https://www.gov.cn/zhengce/202305/content_6858084.htm) |
| 《未成年人网络保护条例》第二十四条第二款 | 不得在**首页首屏、弹窗、热搜**等醒目位置呈现影响未成年人身心健康的信息 | 同上 |
| 《移动互联网未成年人模式建设指南》（网信办 2024-11） | 功能限制只点名「**以未成年人为服务对象的在线教育**不得推送广告等与教学无关的信息」；**未要求全站去广告** | [网信中国](https://gbdsj.gd.gov.cn/zxzx/hydt/content/post_4527646.html) |

> 第二十四条第三款是核心：小程序广告是**算法定向投放**的典型，对未成年用户直接构成「自动化决策商业营销」，属禁止项。
> 该条已在投放侧落地：腾讯广告 FAQ 明确因法定要求对酒水广告**强制**年龄定向为 18–60 岁（「不能面向未成年用户投放」），说明引擎支持按法规做年龄排除。→ [腾讯广告](https://tencentads.com/Faqlist/Detail/642)

## 6. 「未成年模式没广告」的真实机制

微信官方[《未成年人模式功能使用条款》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/y1kiXZeyvPMAFbtW)里**没有任何「关闭广告」的表述**。实测「变清爽」由三件事叠加：

1. **载体入口默认全关**（官方条款原文）：摇一摇、看一看、搜一搜、直播、游戏、购物、微信豆、表情商店「自动关闭、不可访问」。朋友圈、公众号、视频号信息流广告的**展示位本身**随之消失——这是最主要原因。
2. **小程序可整体禁用**：监护人可把小程序设为「不可打开」。
3. **定向能力被切断**：依《条例》第二十四条，微信对未成年账号关停个性化广告定向；广告请求无画像，返回 `errCode 1004`（微信开放文档定义：「无适合的广告」），`ad` 组件此时**不占高度**，页面自然无广告。

> 一句话机制：**不是「拦截了广告」，而是「关掉了广告位 + 不准定向投放」。**

按证据强度排序：**(a) 广告位整体不存在＝主因**（官方条款明列入口自动关闭）；**(d) 感知偏差＝强叠加**（发现页/服务页/支付入口同时精简）；**(c) 填充率下降＝次因**（仅存的视频号只走适龄内容池，常见 1004）；(b) 下发但不显示无证据，不采信。

> 诚实边界：`errCode 1004` 是微信文档的通用无填充码，微信**未公开说明**它由未成年模式触发；第 3 点是基于法规与文档的**合理推断**，非官方确证。朋友圈广告消失有[媒体实测报道](https://m.sohu.com/a/782513420_120914897/)，但同样非官方声明。腾讯广告与微信隐私指引均未披露未成年模式下的标识符（OAID/IDFA）策略。

## 7. 对本模块的取舍建议

| 事项 | 建议 |
|------|------|
| 是否支持小程序广告 | 支持。`activityIds` 加 `com.tencent.mm.plugin.appbrand.` 前缀 + 上述两条规则即可 |
| 激励视频 | 不做。无障碍无法改「看完」状态，属能力边界外的假成功 |
| 优先级 | 低于现有 App 开屏（小程序广告频次低于 App 开屏），排在 [后续计划](后续计划.md) |
| 测试注意 | 微信广告有频次控制，冷启动十次未必出一次，别按单次结果判定规则失效 |
