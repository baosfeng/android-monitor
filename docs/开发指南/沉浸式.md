# 沉浸式

> 一个窗口入口、一个底衬入口、一个覆盖层入口。新页面按本文抄，不再各自 `enableEdgeToEdge` / 自画渐变。

## 1. 三层分工

| 层 | 入口 | 管什么 |
|---|---|---|
| 窗口 | `ui/foundation/MonitorEdgeToEdge.apply(activity)` | 系统栏透明 + 系统栏图标明暗 |
| 底衬 | `Modifier.pageBackdrop()` | `--backdrop-a → --backdrop-b` 竖直渐变，铺满整个窗口 |
| 内容避让 | Scaffold 的 `paddingValues` / `statusBarsPadding()` / `navigationBarsPadding()` | 内容不进系统栏 |

`MainActivity` 只在 `onCreate` 调一次 `MonitorEdgeToEdge.apply(this)`；页面层两件事都不用碰窗口 API。

## 2. 底衬：`Modifier.pageBackdrop()`

```kotlin
Box(Modifier.fillMaxSize().pageBackdrop()) { /* 页面内容 */ }
```

- 渐变按**窗口坐标**计算（用节点在窗口中的位置做偏移），所以页面被 Scaffold inset 让开多少，色值都和工作区外围一致，内容区顶/底不出现接缝。
- 全应用只在这里画页面底衬；`drawWithCache` 缓存 Brush，滚动时不重建。
- 需要给某块面板单独上底时用 token（`t.surface` 等），不要复制渐变。

## 3. 覆盖层：在 Scaffold 之外

整屏覆盖层（滑入页、模态面板）**与 Scaffold 同级**，画在 `MainActivity` 最外层 `Box` 里、`Scaffold` 之后 —— 这样它的底衬/遮罩才铺到状态栏与手势条之下；放进 `Scaffold` 的内容 lambda 会被内容区 padding 裁到系统栏以内。

| 场景 | 用 | 位置 |
|---|---|---|
| 跟随宿主窗口的整层浮层（转场跟页面一起动） | `ImmersiveScrim(visible, onDismiss) { ... }` | `ui/foundation/ImmersiveScrim.kt` |
| 需要独立窗口的弹窗 / 底部抽屉（要压过 systemui 的状态栏窗口） | `WindowOverlay` / `AppDialog` / `BottomSheet` | `ui/components/` |

`ImmersiveScrim` 自带底衬 + 双层 `--scrim` + 返回键/点遮罩关闭；内容自己用 `statusBarsPadding()` / `navigationBarsPadding()` 避让。进出场动画由调用方的 `AnimatedVisibility` 提供。

## 4. 页头 `consumeTopInset`

四套页头（`LiveCards.ScreenHead`、`MainScreen.LiveScreenHead`、`FinanceUIKit.FinanceScreenHead`、`ComponentGalleryScreen.ScreenHead`）都有 `consumeTopInset: Boolean = false`：

- 默认 `false`：页面在 Scaffold 内容区里，状态栏避让已由 Scaffold 的 inset 完成，页头不要再加。
- `true`：页面在 Scaffold 之外（整屏覆盖层），页头自己加 `statusBarsPadding()`。

内容区底部同理：整屏页的内容列补 `navigationBarsPadding()`，否则最后一行被手势条压住。

## 5. 新页面照抄

```kotlin
// Scaffold 内容区里的页面（6 个 Tab、记账子页）
Box(Modifier.fillMaxSize().pageBackdrop()) {
    Column(Modifier.fillMaxSize()) {
        ScreenHead(title = "标题", meta = "副标题")   // consumeTopInset 保持默认
        // 内容：底部用 Scaffold 的 padding
    }
}

// Scaffold 之外的整屏覆盖层（MainActivity 里与 Scaffold 同级）
AnimatedVisibility(visible = show, enter = slideInHorizontally() + fadeIn(), exit = slideOutHorizontally() + fadeOut()) {
    ImmersiveScrim(visible = show, onDismiss = { show = false }) {
        Column(Modifier.fillMaxSize()) {
            ScreenHead(title = "标题", meta = "副标题", onBack = { show = false }, consumeTopInset = true)
        }
    }
}
```
