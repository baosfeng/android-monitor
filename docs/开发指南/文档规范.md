# 文档规范

## 核心原则：Agent-First（Agent 优先）

> ⚠️ **这是本项目的最高文档设计原则，优先级高于所有其他规范。**
>
> 本文档生成的所有文档，**第一消费方是 AI agent**，人类可读是次要目标。所有文档结构、内容粒度、引用方式都必须为 agent 的「快速定位」和「无需 grep」服务。

### 三原则

| # | 原则 | 解释 |
|---|------|------|
| 1 | **模糊表述=缺陷** | 文档中不允许出现"相关代码在 xxx 包下"这类表述，必须写明具体文件路径 |
| 2 | **文件路径是刚需** | 提及的任何类名、接口、组件，必须附带精确文件路径，禁止只写类名不写路径 |
| 3 | **操作意图→文件映射** | 每个模块文档必须包含「操作意图对照表」，让 agent 按图索骥 |

## 语言

- 所有文档**必须使用中文**编写（包括标题、描述、表格内容）
- 代码标识符、关键字、报错信息等源码原文保留不译

## 目录与命名

- 所有文档统一放在 `docs/` 目录下
- 文档文件和目录名**必须使用中文**
- `AGENTS.md` 位于**项目根目录**（不在 `docs/` 内）

## 文档结构

```
docs/
├── 索引.md                  ← 导航入口
├── 概览/                     ← 项目概览文档
│   ├── 项目简介.md
│   ├── 架构总览.md
│   └── 快速上手.md
├── {功能模块目录}/           ← 各功能模块文档
├── 开发指南/                 ← 开发规范文档
├── 踩坑/                    ← 踩坑记录
└── 未归档文档/               ← 待整理的旧文档
```

## 禁止孤立文档

- 每篇文档至少被索引或其他文档引用一次
- 新增文档必须同步更新索引和 AGENTS.md

## 素材与生成物（默认不入库）

仓库只保留**长期有价值、且文档实际引用**的素材；过程取证与生成物默认留在本地。

| 类型 | 例子 | 默认去向 |
|------|------|---------|
| 实施取证 | 逐帧截图、模拟器 / 真机对比图、抓包、原始日志、临时脚本 | 本地目录（如 `.open-design/impl-notes/`），不入库 |
| 生成物 | 原型预览图 `.open-design/*.preview.png` | 本地；需要时从 `.open-design/*.html` 重新生成，不入库 |
| 最终配图 | 文档需要长期展示的截图 / 示意图 | `docs/<模块>/assets/`，并确保文档中引用 |

推荐做法：

- 文档正文优先把结论**内联成文字或表格**（例如「最大偏差 5.1e-5」），保持自包含，不依赖本地取证目录；
- 需要长期展示的图放对应模块的 `docs/<模块>/assets/`，文件名用中文描述用途；
- `.gitignore` 默认忽略 `.open-design/impl-notes/` 与 `.open-design/*.preview.png`，过程产物不会进入 `git status`。
