# 代码规范

## 语言

- 项目使用 **Kotlin** 作为开发语言
- 遵循官方 Kotlin Coding Conventions

## 命名规范

| 元素 | 规范 | 示例 |
|------|------|------|
| 包名 | 全小写，点分隔 | `com.bsfeng.monitor.event` |
| 类/接口 | PascalCase | `EventCollector`, `DatabaseHelper` |
| 函数/方法 | camelCase | `uploadBatch()`, `getDeviceId()` |
| 常量 | 全大写下划线分隔 | `const val CHANNEL_ID_ALERT` |
| 变量/属性 | camelCase | `lastPackageName` |

## 架构规范

- **手动依赖注入**，不引入 Hilt/Dagger 等重型框架
- ViewModel 通过 `viewModel()` 方式获取
- 单例通过 `getInstance()` 懒加载模式（双重校验锁）
- Repository/Service 通过构造方法手动传入
- **优先使用 Android 系统内置 API**，避免引入第三方依赖

## 异步规范

- 使用 Kotlin Coroutines + Flow 处理异步
- IO 操作使用 `Dispatchers.IO`
- UI 层使用 `Dispatchers.Main`

## 数据库访问规范

- 使用 `android.database.sqlite.SQLiteOpenHelper`（系统内置），**不使用 Room**
- 数据库辅助类为 `DatabaseHelper`（`app/src/main/java/com/bsfeng/monitor/data/DatabaseHelper.kt`）
- 数据实体 `EventEntity` 为纯 Kotlin 数据类（无 Room 注解）
- 所有写操作需持有 `writableDatabase`，读操作用 `readableDatabase`
- 批量写操作需显式使用 `beginTransaction()` / `endTransaction()`

## 序列化

- 使用 `org.json.JSONObject` / `JSONArray`（系统内置），**不使用 kotlinx.serialization / Gson / Jackson**
- 数据类提供 `toJson(): JSONObject` 方法用于序列化
- 通过 `JSONObject(extraJson)` 构造方法反序列化字符串

## 网络访问规范

- 使用 `java.net.HttpURLConnection`（系统内置），**不使用 Retrofit / OkHttp**
- 网络工具类为 `ApiService`（`app/src/main/java/com/bsfeng/monitor/network/ApiService.kt`）
- 所有 HTTP 请求封装为 `Result<JsonResponse>` 返回
- 超时时间统一为 10 秒
- 认证 Token 通过 `Authorization: Bearer` 请求头传递

## 测试规范

> **新增代码必须添加对应的测试用例。**

| 原则 | 说明 |
|------|------|
| **全覆盖** | 每新增一个类/方法/功能，必须同时添加单元测试 |
| **三路径** | 测试覆盖正常路径、边界条件、异常场景 |
| **无例外** | 不得以"改动太小"为由跳过测试编写 |
| **并行执行** | 测试任务应使用并行执行以加快反馈 |
