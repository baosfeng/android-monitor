# 功能开关（Feature Flags）

> 一处给默认值，一处读写，关闭即停活。代码在 `app/src/main/java/com/bsfeng/monitor/feature/`。

## 为什么有它

不是所有人都要全部功能（例如传送）。把「功能」当一等公民：开关决定 **Tab 出现与否** 和 **相关后台是否真跑**，
而不是在页面上多一行开关、底下照旧干活。

## 默认值

集中在 `FeatureCatalog.DEFAULTS`，UI 不写字面量默认值。

| 功能 | 默认 | 关掉后停掉的东西 | 接线点 |
|---|---|---|---|
| 实时监控 `LIVE` | 开 | 「实时」Tab 不再生成；该页的 3 秒轮询随订阅消失 | `MainActivity` |
| 广告跳过 `AD_SKIP` | 开 | 切 App 不再开匹配窗口、内容变化不再进规则引擎（不扫节点、不点按钮） | `MonitorAccessibilityService` |
| 记账 `FINANCE` | 开 | 「记账」Tab 不再生成；不创建 `FinanceViewModel`（不读库、不算月统计） | `MainActivity` |
| 传送 `TRANSPORT` | **关** | 传送服务不启动（不绑端口、不发 UDP 公告、不挂通知）、磁贴不可用、不创建 `TransferViewModel` | `TransferEngine.start` / `TransferService` / `TransferTileService` |

口径：**「广告」Tab 不受 `AD_SKIP` 影响**。该 Tab 是广告事件记录页，跳过引擎关掉后记录照常可看。

## 怎么读

| 场景 | 用法 | 说明 |
|---|---|---|
| Compose | `FeatureFlags.get().enabled.collectAsState()` | 开关一变整页重组，不必重启 |
| 热路径（无障碍事件、服务启停） | `FeatureFlags.get().isEnabled(feature)` | 只读内存 `StateFlow`，不碰 SharedPreferences |
| 需要整份快照 | `snapshot()` | 返回不可变 Map，同样不读盘 |
| 纯逻辑测试 | `FeatureFlags(FakeStore())` | 构造注入 `FeatureStore`，纯 JVM 可测 |

写入走 `setEnabled(feature, enabled)`：落盘 + 更新内存 + 通知订阅者，返回 `true` 表示值确实变了
（调用方据此决定弹提示 / 停服务）。

## 写

```kotlin
FeatureFlags.get().setEnabled(Feature.TRANSPORT, true)  // 立即生效
```

`Feature.AD_SKIP` 等枚举自带 `title` / `summary` / `storageKey`；`storageKey` 是持久化键，改名会丢用户选择，保持稳定。

## Tab 与深链

- 可见 Tab：`FeatureCatalog.visibleTabs { isEnabled(it) }`，顺序固定（概览 / 实时 / 广告 / 记账 / 传送 / 设置）。
- 选中 Tab 被关闭：回退概览（`LaunchedEffect(enabledFeatures)`，无需重启）。
- 深链 / 通知：`FeatureCatalog.resolveTab(tab) { isEnabled(it) }`，目标关闭 → 概览；
  `EXTRA_START_TAB` 用 **`AppTab` 枚举下标**（历史顺序），越界或非法一律回退，旧通知不会把 App 打崩。

## 新增一个开关

1. `Feature` 加枚举项 + `FeatureCatalog.DEFAULTS` 给默认值（默认开启就写「不等于关闭名单」，别散在 UI）。
2. 找到该功能 **真正干活的那一处**（服务启动、扫描循环、轮询、ViewModel 构造），在入口判断一次。
3. Compose 侧读 `enabled`，共享状态一变即重组。
4. 设置页「功能」分组加卡：开关 + 专属设置；关闭时把专属设置折叠成一句「开启后可用」，不删入口。
5. 补纯 JVM 单测：默认值、读写、关闭后 `visibleTabs()`。

## 反例

- 只改显示不改行为 → 假开关，用户关掉后仍在耗电/扫描。
- 关闭时在服务入口整体 `return` → 连带停掉实时监控与自动记账（它们共用无障碍服务）。
- 在 `onAccessibilityEvent` 里每次读 SharedPreferences → 主线程热路径抖卡，用内存态。
- 把 `AD_SKIP` 当成「广告」Tab 的开关 → 记录页消失，用户以为数据没了。
