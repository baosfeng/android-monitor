# 编译配置

## JDK 版本要求

> **JDK 必须使用 21。** JDK 25 与 AGP 9.x 存在 jlink 兼容问题，无法正常编译。

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21
```

## 构建变体

| 变体 | 用途 | 说明 |
|------|------|------|
| `debug` | 开发调试 | 启用 R8 代码缩减（isMinifyEnabled = true），不混淆 |
| `release` | 正式发布 | 启用 R8 全量优化 + 混淆 |

> ⚠️ debug 构建启用了 `isMinifyEnabled = true`，但由于 debuggable 标志，R8 的部分优化（混淆/全量内联）被禁用，**代码裁剪（shrinking）仍然生效**。这是 APK 体积控制的重要手段。

## 依赖管理

依赖通过 Maven Central、Google 和阿里云镜像仓库解析（在 `settings.gradle.kts` 中配置）：

```kotlin
repositories {
    maven { url = uri("https://maven.aliyun.com/repository/central") }
    google()
    mavenCentral()
}
```

## 核心依赖

### 已移除的第三方库

| 原依赖 | 替换方案 | 原因 |
|--------|----------|------|
| Room + KSP | `android.database.sqlite.SQLiteOpenHelper` | 系统内置，减少约 1.5 MB DEX 体积 |
| Retrofit + OkHttp | `java.net.HttpURLConnection` | 系统内置，减少约 1.5 MB |
| Kotlinx Serialization | `org.json.JSONObject` | 系统内置，减少约 0.5 MB |
| Kotlinx Serialization 编译器插件 | 无 | 不再需要注解处理器 |
| WorkManager | 无（未被使用） | 直接移除 |
| material-icons-extended | `material-icons-core` | 只用 3 个图标，无需全量图标库 |

### 当前依赖

| 依赖 | 版本 | 说明 |
|------|------|------|
| Compose BOM | 2024.12.01 | Compose UI 物料清单（引入 Material3、UI、Navigation 等） |
| Activity Compose | 1.9.3 | Activity + Compose 集成 |
| Navigation Compose | 2.8.5 | 页面导航 |
| Lifecycle ViewModel Compose | 2.8.7 | ViewModel Compose 集成 |
| Lifecycle Runtime Compose | 2.8.7 | Lifecycle 感知的 Compose |
| material-icons-extended | 跟随 BOM | Material 图标（用于记账模块的分类图标展示） |
| material-icons-core ~~已移除~~ | — | 已被 extended 替换（记账模块需要更多图标） |
| core-ktx | 1.15.0 | Android KTX 核心扩展 |

**所有其他功能（数据库、网络、序列化）均使用 Android 系统内置 API 实现。**

## ProGuard 规则

- **`app/proguard-rules.pro`** — 自定义混淆规则（仅保留注解属性）
- Debug 和 Release 构建均使用 `proguard-android-optimize.txt` 默认规则
