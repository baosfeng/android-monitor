# s09 · 设置 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）。一行 = 一个控件的一种触发；锚点逐字取自原型 `data-od-id`，本节 44 个唯一锚点，不改号、不增删。
> 时长、点击区、行高、触感一律取 [契约口径](_口径/契约口径.md)：按压 120ms · 状态变化 120ms · 浮层入 220ms / 退 150ms · toast 1.6s · 点击区 ≥ 44dp · 行高 ≥ 52dp · 行与开关用 LIGHT。页面转场由 Transitions.kt 统一，本契约不写具体时长。
