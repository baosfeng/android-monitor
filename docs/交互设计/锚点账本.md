# 锚点账本

> 一句话：锚点的唯一事实来源是 `scripts/anchor-ledger.tsv`（制表符分隔，列「锚点 / 来源页面」），本文只说明它怎么用。

## 是什么

| 项 | 说明 |
|---|---|
| 数据文件 | `scripts/anchor-ledger.tsv`——全站页面级锚点，逐字对应原型 `data-od-id` |
| 读者 | `node scripts/check-anchors.mjs`：第一列去重后与代码 `Modifier.testTag` / 映射表常量逐字对账，自增即 exit 1 |
| 反向检查 | 原型 `s\d\d[a-z]?-` 前缀的 `data-od-id` 必须进账本或 `scripts/anchor-retired.tsv`（状态「待实现」+ 屏名理由），两处都没有即 exit 1 并按分片列出 |
| 不收录 | 组件级锚点（`组件名.用途`）见 [s12a-组件级锚点登记](s12a-组件级锚点登记.md)；触发 / 反馈 / 边界写在原型与代码里 |

## 怎么加锚点

1. 给原型元素加 `data-od-id`；2. 往 `scripts/anchor-ledger.tsv` 追加一行「锚点 → 来源页面」（不改号、不转下划线）；本轮不实现的先登 `scripts/anchor-retired.tsv`；3. 代码里 `Modifier.testTag("锚点")`。

三处逐字一致；只改一处会让 `check-anchors.mjs` 报自增或缺失。为什么不放 md：613 行数据表既超单文档上限，又只给脚本读，人看脚本输出即可。
