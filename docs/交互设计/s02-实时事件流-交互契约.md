# s02 · 实时事件流 · 交互契约

> 平台 mobile（Android 竖屏，触屏优先）。锚点逐字取自原型 `data-od-id`，不改号、不新增；本节 24 个锚点全覆盖。
> 触屏只有 click / 长按 / 滑动；外接键盘与 TalkBack 走 focus / 键盘；**本平台不存在 hover**。
> 键盘口径（全屏通用）：所有可点控件 Tab 可达、Enter / Space 等同 click；焦点环 2dp、对比 ≥ 3:1，仅键盘 / 遥控器操作时出现。下表只在行为与这条不同时单列 focus / 键盘 行。
> 时长与尺寸取 token：--dur-press 120ms · --dur-state 120ms · --dur-overlay-in 220ms · --dur-overlay-out 150ms · --dur-page 340ms · --stagger 24ms；toast 1.6s；点击区 ≥ 44dp，事件行 ≥ 52dp。

## 文案口径（逐字，开发照抄）

- 空态：还没有事件 ／ 刷新试试
- 错态：事件流读取失败 ／ 采集服务无响应（AccessibilityService 未连接）。已落库的事件仍可查看。／ 重新连接
- 边界态：11,342 条 ／ 今日窗口已满；字段缺失统一写「—」
- 加载更多：加载更早的事件（还有 118 条）／ 加载中…
- 抽屉：关闭 ／ 复制 JSON ／ toast「已复制事件 JSON」
- toast：已按时间倒序排列 ／ 监控中 · 等待事件 ／ 正在重新连接采集服务…
