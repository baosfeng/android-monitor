# s14a · 记一笔 · 全抽屉 · 交互契约

> 平台：Android 手机竖屏，触屏为主（click / 长按 / 滑动 / 输入）；触屏无 hover，外接键盘不纳入。
> 锚点逐字取自原型 `data-od-id`，不改号、不增删；一行 = 一个控件的一种触发。
> 本屏是新增与编辑共用的唯一表单（顶栏标题在编辑态变「编辑交易」）；动效档为精简时抽屉滑入与滚轮吸附全部落终态。
