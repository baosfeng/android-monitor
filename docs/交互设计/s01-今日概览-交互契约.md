# s01 · 今日概览 · 交互契约

> 平台 mobile（Android 竖屏，触屏优先）。锚点逐字取自原型 `data-od-id`，不改号、不新增；本节 41 个锚点全覆盖。
> 触屏只有 click / 长按 / 滑动；外接键盘与 TalkBack 走 focus / 键盘；**本平台不存在 hover**，按下态即视觉焦点态。
> 键盘口径（全屏通用）：所有可点控件 Tab 可达、Enter / Space 等同 click；焦点环 2dp、对比 ≥ 3:1，仅键盘 / 遥控器操作时出现。下表只在行为与这条不同时单列 focus / 键盘 行。
> 时长与尺寸取 token：--dur-press 120ms · --dur-state 120ms · --dur-overlay-in 220ms · --dur-overlay-out 150ms · --dur-chart 600ms · --dur-page 340ms · --stagger 24ms；toast 1.6s（1.2s 起淡出）；点击区 ≥ 44dp（--tap-min），列表行 ≥ 52dp（--row-min-h）。

## 文案口径（逐字，开发照抄）

- 卡片内空：今天还没有事件 ／ 暂无类型数据 ／ 本周还没有跳过记录 ／ 今天还没有行程
- toast：今日已记录 128 条事件 ／ 正在重新统计…
