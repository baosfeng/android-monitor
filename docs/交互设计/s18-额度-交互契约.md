# s18 · 额度 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）；锚点与 [原型](../../.open-design/src/screens/s18-额度.html) 的 `data-od-id` 逐字相同，共 78 个，不改号、不新增、不删除。
> 一行 = 一个控件的一种触发。触屏为主：click / 长按 / 滑动 / 输入；外接键盘与读屏按 focus / 键盘 补行。
> 时长口径：按压 120ms（--dur-press）· 状态切换 120ms（--dur-state）· 错误条收起 150ms（--dur-overlay-out）· 页面入场 340ms（--dur-page）· 图表 600ms（--dur-chart）· toast 1.6s · 点击区 44dp（--tap-min）。
