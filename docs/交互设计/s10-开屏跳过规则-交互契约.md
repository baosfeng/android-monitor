# s10 · 开屏跳过规则 · 交互契约

> 平台 Android 手机竖屏（minSdk 29）；触屏以 click / 输入 / 滑动为主，外接键盘与 TalkBack 走 focus / 键盘 两行。
> 锚点逐字取自原型 .open-design/src/screens/s10-开屏跳过规则.html 的 data-od-id，共 14 个，不改号、不新增、不删除。
> 时长口径：按下 120ms（--dur-press）· 状态与描边 120ms（--dur-state）· 浮层进 220ms / 出 150ms · 明细展开 220ms（od-rise）· toast 停留 1.6s。
> 触感：开关与行选中 LIGHT，确认类 SUCCESS，同一操作不重复震动。点击区一律 ≥ 44×44dp，行高 ≥ 52dp。
