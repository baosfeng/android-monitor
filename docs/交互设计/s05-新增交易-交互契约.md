# s05 · 新增交易 · 交互契约

> 平台：Android 手机竖屏，触屏为主（click / 长按 / 滑动 / 输入）；触屏无 hover，外接键盘不纳入。
> 锚点逐字取自原型 `data-od-id`，不改号、不增删；一行 = 一个控件的一种触发。金额行含「输入」触发，单独成行。
> 动效档为精简时，缩放、数字滚动、抽屉滑入全部落终态。
