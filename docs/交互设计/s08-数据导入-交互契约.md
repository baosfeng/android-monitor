# s08 · 数据导入 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）；触屏为主，外接键盘按 focus / 键盘 实现，hover 不适用。
> 锚点逐字取自原型 `data-od-id`，不改号、不新增；本节 19 个锚点。
> 口径：进度 120ms 线性推进，数字 620ms 滚动，卡片进场 300ms / 错峰 24ms，收放 150–220ms，toast 停留 1.6s。
