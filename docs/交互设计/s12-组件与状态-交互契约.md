# s12 · 组件与状态 · 交互契约

> 平台 Android 手机竖屏（minSdk 29）。本屏是组件与五态的参照展厅：表里每一行同时是该项目内同名组件的通用交互口径。
> 锚点逐字取自原型 .open-design/src/screens/s12-组件与状态.html 的 data-od-id，共 18 个，不改号、不新增、不删除。
> 时长口径：按下 120ms（--dur-press）· 状态与描边 120ms（--dur-state）· 浮层进 220ms / 出 150ms · 图表 600ms（--dur-chart）· 进度条 700ms 延迟 120ms · toast 停留 1.6s。
> 触感：按钮 / 开关 / chip / 分段 / 行点击均 LIGHT，同一操作不重复震动。点击区 ≥ 44×44dp，行高 ≥ 52dp。
