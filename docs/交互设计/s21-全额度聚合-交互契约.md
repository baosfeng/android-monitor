# s21 · 全额度聚合 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）；锚点与 [原型](../../.open-design/src/screens/s21-全额度聚合.html) 的 `data-od-id` 逐字相同，共 58 个（含 1 个错挂锚点与 24 个外壳 / 演示件，见文末附录），不改号、不新增、不删除。
> 本屏与 s20 的差别：余额型（¥）也进榜，靠「紧迫档」把 % 与 ¥ 放在同一张榜上；本表只写「点下去怎么变」，分档算法见文末待确认项。
> 时长口径：按下与状态变化 120ms（--dur-press / --dur-state）· 开屏 220ms 入 / 930ms 后 115ms 出 · toast 停留 1.6s · 点击区 ≥44×44dp（[口径](_口径/契约口径.md)）。

## 演示件与原型外壳锚点（不计入产品契约）

> 本分片骨架尾部混入原型外壳与演示件锚点 25 个（`demo-only:` 4 个 + dev / theme / state 20 个 + 错挂的 `s04-list` 1 个）。它们不是额度屏的控件，产品内不渲染；按技能口径不进产品契约表，行为在此逐一点名留档。

**状态演示件（`demo-only:`，4 个）**

- `demo-only:s21-probe`（虚线评审条）：click 无反应；产品内不存在。
- `demo-only:s21-scen-normal`（「正常」）：click 归一为正常态——deepseek 显示「约还能撑 6 天 · 按近 7 天日均 ¥4.7」，ollama 不带「旧数据」，条色回档位色。
- `demo-only:s21-scen-nodegrade`（「算不出日均」）：click 只把 deepseek 副行换成「未配用量令牌 · 仅按低余额阈值 ¥50 判断」；档位、位次、条长都不动（阈值 ¥50 仍判最急）。
- `demo-only:s21-scen-stale`（「查询失败」）：click 让 ollama 出「旧数据」标签、条色转降饱和琥珀，位次不动。

**原型外壳演示件（20 个）**

- `devbar` / `dev-toggle`（「原型控制」按钮）：click 220ms 展开 / 收起控制面板，按钮 aria-expanded 同步翻转；产品内不存在。
- `dev-panel`：click 无反应（面板容器）；产品内不存在。
- `theme-picker` 与 `theme-apple` / `theme-glassmorphism` / `theme-notion` / `theme-stripe` / `theme-claude` / `theme-ibm` / `theme-kami` / `theme-bento`（8 个主题项）：click 该项选中态 120ms、其余取消选中，整页 token 换肤；产品内主题由设置页控制，不在此屏切换。
- `state-demo` 与 `state-loading` / `state-empty` / `state-error` / `state-populated` / `state-edge`：click 把当前屏切到对应五态用于评审；产品内五态由真实数据推导，不可手动切。
- `dev-replay`（「重播开屏」）：click 重播一次开屏层；仅评审用。
- `dev-toast`（「Toast」）：click 弹一条示例 toast；仅评审用。
- `dev-autobook`（「自动记账浮窗」）/ `dev-autocommit`（「模拟自动记账落库」）/ `dev-autoswitch`（「浮窗演示：切到记账页（浮窗不关闭）」）：click 触发自动记账浮窗相关演示，与额度无关。
- `dev-s20a`（「额度聚合 · 方案A」）/ `dev-s20b`（「额度聚合 · 方案B」）/ `dev-s21`（「全额度聚合」）：click 直接跳对应对照屏；仅评审用，产品内聚合只有一种形态。
- `s04-list`（记账页列表容器）：错挂进本分片骨架，属记账屏，与本屏无关。

> [待确认] 分档口径——百分比型按「剩余 <20% 为最急档、<50% 为偏低档」，余额型按「能撑天数 <7 / <30」或低余额阈值（CNY 50 / USD 5）判档，同档内余额型排百分比型之后。当前按此写死；若产品要统一阈值，需先改文案「按紧迫度分档，同档按剩余」。
> [待确认] 余额型算不出日均时，条长用「余额 ÷ 阈值×2」而不是按档位固定长度——两种读数在同一屏并存，是否需要统一由 leader 定。
