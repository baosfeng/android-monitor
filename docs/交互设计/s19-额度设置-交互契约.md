# s19 · 额度设置 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）；锚点与 [原型](../../.open-design/src/screens/s19-额度设置.html) 的 `data-od-id` 逐字相同，共 16 个，不改号、不新增、不删除。
> 一行 = 一个控件的一种触发。触屏为主：click / 输入 / 滑动；外接键盘与读屏按 focus / 键盘 补行。
> 时长口径：按下与状态变化 120ms（--dur-press / --dur-state）· 浮层进 220ms / 出 150ms · toast 停留 1.6s（[口径](_口径/契约口径.md)）。
> 触感：开关与行选中 LIGHT、保存类 SUCCESS，同一操作不重复震动。点击区一律 ≥ 44×44dp，行高 ≥ 52dp。
