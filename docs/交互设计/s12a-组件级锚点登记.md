# s12a · 组件级锚点登记

> 何时读：给通用组件加可交互元素，或写 Compose 测试要定位组件时。本文只登记代码里的稳定标识串，不描述行为（行为口径见 s12）。
> 为什么单开一页：s12 的锚点逐字取自原型 data-od-id、不允许自造；组件级标识是另一件事 —— 它保证每个可交互元素都能被自动化定位，由 scripts/check-a11y.sh 与 scripts/debug-cli.sh ui audit 两道门禁守。

## 命名口径

- 组件级：组件名.用途（chip.option / button.primary / row.tx）。
- 页面级：页面.区域.元素（overview.kpi.events）。
- 列表行：固定前缀、允许多实例，测试用 onAllNodesWithTag 取集合。
- 同一节点不叠第二个 testTag：后写的会顶掉调用方的 sXX-* 锚点，组件标识改打在内部子节点上。
- Glance（RemoteViews）没有 testTag(...) 函数，写 semantics { testTag = "…" }，门禁两种写法都认。
