# s04 · 记账 · 交互契约

> 平台：Android 手机竖屏，触屏为主（触发＝click / 长按 / 滑动；本屏无输入框，故无 输入；触屏无 hover）。
> 锚点逐字取自原型 `data-od-id`，不改号、不增删；一行 = 一个控件的一种触发。
> 反馈列写「用户感知到什么」：视觉变化 + 文案原文 + 时长。动效档为精简时，缩放与惯性滑行全部落终态。
