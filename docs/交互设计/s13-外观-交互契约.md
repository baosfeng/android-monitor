# s13 · 外观 · 交互契约

> 平台 mobile（Android 手机竖屏，minSdk 29）。一行 = 一个控件的一种触发；锚点逐字取自原型 `data-od-id`，本节 19 个唯一锚点，不改号、不增删。
> 时长、点击区、行高、触感一律取 [契约口径](_口径/契约口径.md)：按压 120ms · 状态变化 120ms · 浮层入 220ms / 退 150ms · toast 1.6s · 点击区 ≥ 44dp · 行高 ≥ 52dp · 选项与开关用 LIGHT。页面转场由 Transitions.kt 统一，本契约不写具体时长；数字滚动与图表动画由动效档位决定。
> 本屏是「选项即生效」页：选中即时切换、无保存按钮、无二次确认。选中态只用描边加粗 + 字重提升（fg 40% 描边、字重 600、--elev-1），不占强调色预算。
