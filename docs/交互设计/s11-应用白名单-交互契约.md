# s11 · 应用白名单 · 交互契约

> 平台 Android 手机竖屏（minSdk 29）；触屏以 click / 输入 / 滑动为主，外接键盘与 TalkBack 走 focus / 键盘 两行。
> 锚点逐字取自原型 .open-design/src/screens/s11-应用白名单.html 的 data-od-id，共 10 个，不改号、不新增、不删除。
> 时长口径：按下 120ms（--dur-press）· 状态与描边 120ms（--dur-state）· 空态卡片出现 / 消失 150ms · toast 停留 1.6s。
> 触感：开关、快捷筛选 chip、清空搜索均 LIGHT。点击区 ≥ 44×44dp，应用行高 ≥ 52dp。
