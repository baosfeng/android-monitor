# 数据持久化模块

**包路径:** `com.bsfeng.monitor.data`

**文件路径:** `app/src/main/java/com/bsfeng/monitor/data/`

## 模块职责

基于 `android.database.sqlite.SQLiteOpenHelper`（系统内置）的本地 SQLite 持久化层，负责事件数据的本地缓存、离线存储、按条件查询和批量清理。是事件采集层与网络上报层之间的数据缓冲区。

## 架构位置

```
EventCollector (事件处理层)
    ↓ 写入
DatabaseHelper (持久化层)
    ↓ 读取
EventReporter (上报层)
```

## 核心文件

| 文件 | 职责 |
|------|------|
| `app/src/main/java/com/bsfeng/monitor/data/DatabaseHelper.kt` | SQLiteOpenHelper 实现，单例管理，建库建表，所有 CRUD 操作 |
| `app/src/main/java/com/bsfeng/monitor/data/EventEntity.kt` | 数据实体（纯 Kotlin 数据类），`fromEvent()` 工厂方法 |

> `AppDatabase.kt` 和 `EventDao.kt`（Room 版本）已移除，被 `DatabaseHelper` 取代。

## 数据库

| 属性 | 值 |
|------|-----|
| 数据库文件名 | `monitor.db` |
| 数据库版本 | 1 |
| 单例方式 | `DatabaseHelper.getInstance(context)` — 双重检查锁定懒加载 |
| 实体 | `EventEntity`（表名 `events`） |

## 表结构：`events`

| 列名 | Kotlin 类型 | SQL 类型 | 约束 | 说明 |
|------|------------|---------|------|------|
| `eventId` | `String` | `TEXT` | `PRIMARY KEY` | 事件唯一 ID |
| `eventType` | `String` | `TEXT` | — | 事件类型标识 |
| `timestampMs` | `Long` | `INTEGER` | — | 事件发生时间戳（毫秒） |
| `deviceId` | `String` | `TEXT` | — | 设备标识 |
| `extraJson` | `String` | `TEXT` | — | 附加数据（JSON 字符串） |
| `isUploaded` | `Boolean` | `INTEGER` | 默认 `0` | 是否已成功上报 |
| `createdAt` | `Long` | `INTEGER` | 默认当前时间 | 记录创建时间戳（毫秒） |

索引：`idx_events_uploaded`（`isUploaded`）、`idx_events_timestamp`（`timestampMs`）

## 操作方法清单

### 写入操作

| 方法 | 签名 | 说明 |
|------|------|------|
| `insert` | `fun insert(event: EventEntity)` | 插入单条事件，冲突时忽略 |
| `insertAll` | `fun insertAll(events: List<EventEntity>)` | 批量插入（事务包装），冲突时忽略 |

### 查询操作

| 方法 | 签名 | 说明 |
|------|------|------|
| `getUnsentEvents` | `fun getUnsentEvents(limit: Int = 50): List<EventEntity>` | 查询未上传事件，按时间升序，最多 `limit` 条 |
| `getRecentEvents` | `fun getRecentEvents(limit: Int = 50): List<EventEntity>` | 查询最近事件，按时间降序，最多 `limit` 条 |
| `countUnsent` | `fun countUnsent(): Int` | 统计未上传事件总数 |
| `countByTypeSince` | `fun countByTypeSince(since: Long, type: String): Int` | 统计指定时间戳之后、指定类型的事件数量 |

### 更新 / 删除操作

| 方法 | 签名 | 说明 |
|------|------|------|
| `markUploaded` | `fun markUploaded(ids: List<String>)` | 将指定 ID 列表的事件标记为已上传 |
| `cleanOldEvents` | `fun cleanOldEvents(before: Long)` | 删除 `before` 之前且已上传的旧事件 |

> 以上所有方法均为**同步阻塞**调用。调用方应在 `Dispatchers.IO` 上执行。

## 工厂方法：`EventEntity.fromEvent()`

**文件路径:** `app/src/main/java/com/bsfeng/monitor/data/EventEntity.kt`

```kotlin
fun fromEvent(
    eventId: String,
    eventType: String,
    extraJson: String,
    deviceId: String
): EventEntity
```

自动填充 `timestampMs = System.currentTimeMillis()`、`isUploaded = false`，`createdAt` 使用实体默认值。

## 使用方式

```kotlin
// 获取数据库实例
val db = DatabaseHelper.getInstance(context)

// 写入事件
db.insert(EventEntity.fromEvent(id, type, extra, deviceId))

// 批量写入
db.insertAll(entities)

// 查询未上传事件
val unsent = db.getUnsentEvents(limit = 50)

// 标记已上传
db.markUploaded(listOf("eventId1", "eventId2"))

// 清理旧数据
db.cleanOldEvents(before = cutoffTimestamp)

// 统计未上传数量
val count = db.countUnsent()
```
