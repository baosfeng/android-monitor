# 分类体系实现计划

> 依据：[分类体系设计](../记账/分类体系设计.md)。执行顺序：数据与迁移 → 识别映射 / 两级选择器（可并行）→ 展示与文档。

**Goal:** 把扁平分类升级为「一级 + 二级」，统计与预算按一级汇总，自动记账映射到二级。

**Architecture:** 分类表沿用 `parent_id`（一级 -1，二级指向一级 id）；新增纯逻辑 `CategoryTree` 做父子映射与一级聚合，`CategoryCatalog` 作为唯一分类种子；`FinanceManager` 启动时一次性迁移并把交易/预算归到一级；UI 用两级选择器，统计/预算只消费一级。

**Tech Stack:** Kotlin、Compose、SQLiteOpenHelper、JUnit4 + Robolectric；JDK 21。

## Global Constraints

- 每个任务先写测试再实现；提交前 `export JAVA_HOME=/opt/homebrew/opt/openjdk@21 && ./gradlew test` 全绿。
- 分类名称全局唯一；二级不得与一级同名；收入/支出分类隔离。
- 统计、预算只按一级；交易列表显示二级名（无二级显示一级）。
- UI 颜色/圆角/间距走 `LocalDesignTokens`；不新增第三方依赖。
- 不操作手机界面（不做 adb input/monkey）；每次交付构建 APK。
