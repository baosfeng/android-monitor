## 交互契约（原型即验收标准）

1. **关闭**：只有「记一笔」「忽略」能让浮窗消失；点遮罩只吞点击并提示；切到记账页浮窗保持。
2. **说明**：可编辑一行，占位「写一下买了什么」；只存用户手写内容，不拼商户 / 商品 / 付款方式。
3. **分类**：默认一级 18 个（6 列 3 行）；点一级才展开二级；识别项自动展开、高亮、滚入视野；二级必选。
4. **刷新**：自动记账落库后，记账列表顶部立即出现新行（「自动」徽标 + 高亮 1.6s），同时 toast 提示。
5. **去重**：记一笔 / 忽略各 10 分钟；忽略落盘 7 天。

## 设计决策（本轮的取舍）

- **一屏信息密度优先**：列表默认只放一级，二级折叠；抽屉 / 浮窗内内容区可滚动、按钮固定底部，展开二级不把主操作挤出屏幕。
- **分类格恢复旧版口径**：32dp 线描图标、无灰底、选中 2dp accent 描边；一级二级同构，不再用彩色圆底。
- **刷新用「顶部插入 + 高亮」**：不做整页 reload，避免滚动位置丢失。
- **浮窗调试入口放 devbar**：卡片内不出现原型调试按钮。
