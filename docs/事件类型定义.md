# 事件类型定义

本文档定义所有可采集的事件类型及其数据结构。每条事件记录均采用统一 JSON 格式上报。

---

## 1. 统一事件基结构

所有事件共享以下字段：

```json
{
  "event_id": "xxxx-xxxx-xxxx-xxxx",       
  "event_type": "app_foreground",          
  "timestamp": 1718000000123,              
  "device_id": "device_uuid",              
  "extra": {}                             
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event_id` | string (UUID v4) | 全局唯一事件 ID |
| `event_type` | string | 事件类型枚举值，见第 3 节 |
| `timestamp` | int64 | 事件发生的 Unix 毫秒时间戳 |
| `device_id` | string | 设备唯一标识（首次启动生成并持久化） |
| `extra` | object | 事件特有字段，各事件类型的 extra 定义见下文 |

---

## 2. 事件类型完整清单（V1 全部实现）

### 2.1 `app_foreground` — 前台 App 切换

**触发条件**: 用户从前台切换到另一个 App，或从桌面启动 App。

```json
{
  "event_type": "app_foreground",
  "extra": {
    "package_name": "com.tencent.mm",
    "app_name": "微信",
    "activity_name": ".ui.LauncherUI",
    "activity_class": "com.tencent.mm.ui.LauncherUI",
    "is_from_recent": false,
    "from_package": "com.miui.home",
    "from_activity": ".launcher.Launcher",
    "foreground_duration_ms": 30500
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `package_name` | string | 是 | App 包名 |
| `app_name` | string | 是 | 用户可读的应用名（通过 PackageManager 获取） |
| `activity_name` | string | 是 | 当前 Activity 的简短类名 |
| `activity_class` | string | 是 | 完整的 Activity 类名 |
| `is_from_recent` | boolean | 是 | 是否从多任务切换而来 |
| `from_package` | string | 否 | 跳转来源包名（首次启动为桌面包名） |
| `from_activity` | string | 否 | 跳转来源 Activity 名称 |
| `foreground_duration_ms` | int64 | 否 | 上一个 App 的停留时长（毫秒），首次为 0 |

---

### 2.2 `activity_change` — Activity 级界面切换

**触发条件**: 同一 App 内的界面跳转（如微信首页 → 朋友圈）。

```json
{
  "event_type": "activity_change",
  "extra": {
    "package_name": "com.tencent.mm",
    "app_name": "微信",
    "from_activity": ".ui.LauncherUI",
    "to_activity": ".plugin.sns.ui.SnsTimeLineUI",
    "from_class": "com.tencent.mm.ui.LauncherUI",
    "to_class": "com.tencent.mm.plugin.sns.ui.SnsTimeLineUI",
    "intent_action": null,
    "intent_categories": ["android.intent.category.LAUNCHER"],
    "is_root": false
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `package_name` | string | 是 | App 包名 |
| `app_name` | string | 是 | 应用名 |
| `from_activity` / `to_activity` | string | 是 | 界面类名（简写/完整各一份） |
| `from_class` / `to_class` | string | 是 | 完整类名 |
| `intent_action` | string 或 null | 是 | Intent Action 值 |
| `intent_categories` | string[] | 是 | Intent Category 列表 |
| `is_root` | boolean | 是 | 是否为该 App 的入口 Activity |

---

### 2.3 `screen_on` — 屏幕亮起

**触发条件**: 设备屏幕点亮（按电源键/双击亮屏/抬起亮屏等）。

```json
{
  "event_type": "screen_on",
  "extra": {
    "trigger_source": "power_button",
    "is_keyguard_locked": true
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `trigger_source` | string | 是 | 触发源枚举：`power_button` / `double_tap` / `raise_wake` / `notification` / `other` |
| `is_keyguard_locked` | boolean | 是 | 亮起时是否处于锁屏状态（true=需要解锁，false=已解锁） |

---

### 2.4 `screen_off` — 屏幕熄灭

**触发条件**: 设备屏幕熄灭（超时休眠 / 按电源键关屏）。

```json
{
  "event_type": "screen_off",
  "extra": {
    "trigger_source": "timeout",
    "screen_on_duration_ms": 120000,
    "is_charging": false
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `trigger_source` | string | 是 | 触发源枚举：`timeout` / `power_button` / `proximity` / `other` |
| `screen_on_duration_ms` | int64 | 是 | 上一次亮屏持续时长（毫秒） |
| `is_charging` | boolean | 是 | 关屏时是否正在充电 |

---

### 2.5 `unlock_success` — 解锁成功

**触发条件**: 用户成功解锁手机（锁屏 → 主屏幕）。

```json
{
  "event_type": "unlock_success",
  "extra": {
    "unlock_method": "fingerprint",
    "locked_duration_ms": 4500,
    "failed_attempts_since_last_success": 0
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `unlock_method` | string | 是 | 解锁方式枚举：`pin` / `password` / `pattern` / `fingerprint` / `face` / `iris` / `none`（无锁屏） |
| `locked_duration_ms` | int64 | 是 | 从关屏/锁屏到解锁成功的耗时（毫秒） |
| `failed_attempts_since_last_success` | int | 是 | 本次解锁前连续失败次数 |

---

### 2.6 `unlock_failed` — 解锁失败

**触发条件**: 用户解锁失败（密码/指纹错误等）。

```json
{
  "event_type": "unlock_failed",
  "extra": {
    "unlock_method": "fingerprint",
    "error_reason": "fingerprint_not_recognized",
    "failed_attempts_total": 3
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `unlock_method` | string | 是 | 解锁方式，同 `unlock_success` |
| `error_reason` | string | 是 | 失败原因枚举：`wrong_pin` / `wrong_pattern` / `wrong_password` / `fingerprint_not_recognized` / `face_not_recognized` / `timeout` / `cancel` |
| `failed_attempts_total` | int | 是 | 锁屏期间累计失败次数 |

---

### 2.7 `charging_started` — 开始充电

**触发条件**: 插入充电器。

```json
{
  "event_type": "charging_started",
  "extra": {
    "charge_type": "usb",
    "battery_level": 15,
    "is_fast_charge": false,
    "is_wireless": false
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `charge_type` | string | 是 | 枚举：`usb` / `ac` / `wireless` / `unknown` |
| `battery_level` | int | 是 | 开始充电时的电量百分比 0-100 |
| `is_fast_charge` | boolean | 是 | 是否快充 |
| `is_wireless` | boolean | 是 | 是否无线充电 |

---

### 2.8 `charging_stopped` — 停止充电

**触发条件**: 拔下充电器或充满自动断充。

```json
{
  "event_type": "charging_stopped",
  "extra": {
    "charge_type": "usb",
    "battery_level": 78,
    "charged_duration_ms": 3600000,
    "battery_level_start": 15,
    "battery_level_end": 78,
    "reason": "unplugged"
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `charge_type` | string | 是 | 充电方式 |
| `battery_level` | int | 是 | 停止充电时的电量 |
| `charged_duration_ms` | int64 | 是 | 本次充电持续时长（毫秒） |
| `battery_level_start` | int | 是 | 本次充电开始电量 |
| `battery_level_end` | int | 是 | 本次充电结束电量 |
| `reason` | string | 是 | 停止原因枚举：`unplugged` / `full` / `error` |

---

### 2.9 `wifi_connected` — WiFi 连接

**触发条件**: 手机连接到 WiFi 网络。

```json
{
  "event_type": "wifi_connected",
  "extra": {
    "ssid": "MyHomeWiFi",
    "bssid": "xx:xx:xx:xx:xx:xx",
    "signal_strength": -55,
    "frequency_mhz": 5180,
    "is_5ghz": true,
    "is_hidden": false,
    "ip_address": "192.168.1.100"
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ssid` | string | 是 | WiFi 名称 |
| `bssid` | string | 是 | 路由器 MAC 地址（可做匿名哈希处理） |
| `signal_strength` | int | 是 | RSSI 信号强度 dBm |
| `frequency_mhz` | int | 是 | 频段 MHz |
| `is_5ghz` | boolean | 是 | 是否为 5GHz 频段 |
| `is_hidden` | boolean | 是 | 是否为隐藏网络 |
| `ip_address` | string | 是 | 设备获取的 IP 地址 |

---

### 2.10 `wifi_disconnected` — WiFi 断开

**触发条件**: 手机断开 WiFi 连接。

```json
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ssid` | string | 是 | 断开时的 WiFi 名称 |
| `bssid` | string | 是 | 断开时的路由器 MAC |
| `connected_duration_ms` | int64 | 是 | 本次连接持续多久 |
| `reason` | string | 是 | 断开原因枚举：`disconnected` / `lost` / `assoc_reject` / `auth_error` / `dhcp_fail` |


| 字段 | 类型 | 必填 | 说明 |

### 2.15 `notification_received` — 通知到达

**触发条件**: 系统收到通知（显示到通知栏）。

> ⚠️ **隐私说明**: 默认不上报通知文本内容，仅上报元数据。如需打开内容上报，需用户主动在 App 内确认授权。

```json
{
  "event_type": "notification_received",
  "extra": {
    "package_name": "com.tencent.mm",
    "app_name": "微信",
    "category": "msg",
    "priority": 1,
    "is_group": false,
    "has_actions": true,
    "posted_time_ms": 1718000000123,
    "content_abstract": "[一条消息]"
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `package_name` | string | 是 | 发送通知的 App 包名 |
| `app_name` | string | 是 | 应用名 |
| `category` | string | 是 | 通知分类（系统自带分类如 `msg` / `call` / `alarm` / `social` 等，或 App 自定义） |
| `priority` | int | 是 | 通知优先级 -2~2 |
| `is_group` | boolean | 是 | 是否为分组通知 |
| `has_actions` | boolean | 是 | 是否包含快捷操作按钮 |
| `posted_time_ms` | int64 | 是 | 通知到达时间 |
| `content_abstract` | string | 否 | 内容摘要（默认隐藏，可配置开启；截取前 20 个字） |

---

### 2.16 `notification_removed` — 通知移除

**触发条件**: 通知被用户滑掉或者 App 取消。

```json
{

    "removal_reason": "swiped",
    "shown_duration_ms": 120000
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `package_name` | string | 是 | 包名 |
| `notification_id` | int | 是 | 通知 ID |
| `removal_reason` | string | 是 | 移除原因枚举：`swiped` / `cancelled` / `clicked` / `group_collapsed` / `other` |
| `shown_duration_ms` | int64 | 是 | 通知从到达至移除的时长（毫秒） |

### 2.17 `battery_changed` — 电池电量变化

**触发条件**: 电量变化 ≥ 1%，或充电状态变化。

```json
{
  "event_type": "battery_changed",
  "extra": {
    "battery_level": 45,
    "is_charging": false,
    "charge_type": "none",
    "temperature_celsius": 36.5,
    "voltage_mv": 3800,
    "health": "good",
    "plugged_duration_ms_since_last_full": 0
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `battery_level` | int | 是 | 当前电量 0-100 |
| `is_charging` | boolean | 是 | 是否在充电 |
| `charge_type` | string | 是 | 充电方式枚举：`none` / `usb` / `ac` / `wireless` / `unknown` |
| `temperature_celsius` | float | 是 | 电池温度摄氏度 |
| `voltage_mv` | int | 是 | 电池电压毫伏 |
| `health` | string | 是 | 电池健康状态枚举：`good` / `overheat` / `over_voltage` / `unknown` / `dead` |
| `plugged_duration_ms_since_last_full` | int64 | 否 | 上次满电后累计充电时长 |

---

## 3. 事件类型枚举汇总

| 事件类型标识 | 说明 | 数据量估算 |
|-------------|------|-----------|
| `app_foreground` | 前台 App 切换 | 高 |
| `activity_change` | Activity 级界面切换 | 很高 |
| `screen_on` | 屏幕亮起 | 中 |
| `screen_off` | 屏幕熄灭 | 中 |
| `unlock_success` | 解锁成功 | 中 |
| `unlock_failed` | 解锁失败 | 低 |
| `charging_started` | 开始充电 | 低 |
| `charging_stopped` | 停止充电 | 低 |
| `wifi_connected` | WiFi 连接 | 低 |
| `wifi_disconnected` | WiFi 断开 | 低 |
| `headset_plugged` | 耳机插入 | 低 |
| `headset_unplugged` | 耳机拔出 | 低 |
| `app_installed` | 应用安装 | 极低 |
| `app_uninstalled` | 应用卸载 | 极低 |
| `notification_received` | 通知到达 | 高 |
| `notification_removed` | 通知移除 | 高 |
| `battery_changed` | 电量变化 | 中 |
| `ringer_mode_changed` | 情景模式变化 | 低 |
| `connected_to_pc` | 连接电脑 | 低 |
| `disconnected_from_pc` | 断开电脑 | 低 |

## 4. 上报批量结构

Android 端将多条事件打包后上报：

```json
{
  "events": [
    { /* 事件 1 完整结构 */ },
    { /* 事件 2 完整结构 */ },
    { /* 事件 3 完整结构 */ }
  ],
  "batch_id": "batch-uuid",
  "device_id": "device-uuid",
  "batch_created_at_ms": 1718000000123,
  "batch_size": 3
}
```
